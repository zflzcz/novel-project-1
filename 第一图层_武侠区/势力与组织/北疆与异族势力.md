## 一、异族势力总论

第一图层的"天下"并非仅属于中原皇朝——在大陆的边缘，存在着多个与中原截然不同的文明体系。他们是系统为第一图层精心设计的**"永恒冲突引擎"的外部组件**。

> **《历史的地理枢纽》**："谁控制了心脏地带，谁就控制了世界岛。" 北疆草原正是第一图层的"心脏地带"——广袤无垠的草原是铁骑的高速公路，中原的长城防线是唯一的人工屏障。

## 二、苍狼汗国 —— "草原之上，唯铁蹄与天道"

| 项目 | 内容 |
|------|------|
| **性质** | 游牧帝国 |
| **领地** | 北疆温带草原（纬度40°~55°N）——"心脏地带" |
| **核心资源** | 沉星寒铁（军工命脉）、龙驹血马（骑兵之本） |
| **现任大汗** | 阿骨烈·苍狼汗（"铁汗"），宗师境上阶 |
| **军力** | 铁骑约八万，其中精锐"狼骑"约一万 |

### 2.1 汗国历史

苍狼汗国并非一个持续存在的帝国——它如同草原上的野火，周期性地燃起和熄灭。

| 时期 | 状态 | 关键事件 |
|------|------|---------|
| 仙人纪 | 散居部落 | 草原游牧民以百人规模的血缘群落生活 |
| 封锁纪 | 部落联盟 | 第一次统一尝试——"天狼汗"统一北疆西部 |
| 诸国纪·第一次南下 | 帝国 | 苍狼大汗突破天象境，铁骑踏破长城，建立天元朝 |
| 天元朝覆灭后 | 再次碎裂 | 大汗陨落，北疆重新分裂为数十个部落 |
| 景朝初期 | 内战 | 各部争夺"苍狼汗"称号，长达百年的草原内战 |
| **当世** | **再次统一** | 阿骨烈以铁血手段统一草原十三部，自称"铁汗" |

### 2.2 游牧vs农耕——永恒的冲突模式

> **《枪炮、病菌与钢铁》**："蒙古游牧民曾直接摧毁了伊朗、伊拉克的古代灌溉系统。"
> **《星球构建工具箱》**："游牧民族的军事优势在于——他们几乎就是一支纯粹的军队。所有成年男性都是骑兵且从小训练弓箭。"

| 维度 | 苍狼汗国（游牧） | 景朝（农耕） |
|------|---------------|------------|
| **军事** | 全民皆兵——男子五岁上马、十岁拉弓 | 职业军人+征召农民民兵 |
| **机动性** | 极强——无城池无固定据点，来去如风 | 极弱——必须死守城池和农田 |
| **后勤** | 牛羊即食物，几乎无后勤需求 | 漫长的补给线，粮草是命脉 |
| **耐久** | 差——无法长期围城，缺乏攻城器械 | 强——城墙和防御工事 |
| **经济** | 极其脆弱——草场退化即全族饥荒 | 相对稳定——但依赖息渊土 |

> **系统设计**：草原与中原的冲突是系统精心编排的。每当"三百年天灾"来临，北疆降水率被系统脚本下调→草场退化→游牧民族被迫南下→铁骑与农耕帝国血战→海量的恐惧、绝望、仇恨情感数据被收割。

### 2.3 阿骨烈·铁汗——当世最危险的人

| 要素 | 内容 |
|------|------|
| **年龄** | 四十七岁 |
| **境界** | 宗师境上阶（北疆近百年来最强的大汗） |
| **武学** | 草原外家刚猛系——马上枪术+鹰爪功。风格暴烈直接 |
| **性格** | 冷酷、精明、耐心。不同于前代大汗的莽撞，他懂得"等待" |
| **野心** | 统一草原仅是第一步——他的真正目标是**踏破长城，重建天元朝** |

阿骨烈的可怕之处不在于武力——而在于**政治头脑**。他统一草原后没有立刻南下，而是：

1. **整合经济**：控制北疆所有沉星寒铁矿脉，将铁矿加工纳入汗国垄断
2. **训练军队**：将十三部零散骑兵整编为统一的军制（万人队→千人队→百人队）
3. **情报渗透**：派遣伪装成马贩和皮货商的探子深入中原，摸清景朝虚实
4. **等待时机**：他知道三百年周期律已经"迟到"了约五十年——天灾一旦降临，就是南下的最佳窗口

> **《君主论》映射**："一个英明的君主应当……在和平时期也不能闲着不干事，而要用勤勉刻苦来积蓄实力，以便在命运逆转时可有准备和力量来抵御打击。"阿骨烈正是这样的"英明君主"。

### 2.4 汗国内部势力

| 部落/派系 | 态度 | 关键 |
|---------|------|------|
| **狼部**（铁汗直属） | 核心 | 铁汗亲军"狼骑"一万，绝对忠诚 |
| **鹰部** | 顺从 | 北疆东部最大部落，被铁汗以联姻拉拢 |
| **马部** | 暗藏不满 | 控制龙驹血马马场，对铁汗的中央集权不满 |
| **白骨部** | 表面臣服 | 北疆最北端苦寒部落，与血衣侯有秘密联系 |

## 三、南荒蛊族联盟 —— "瘴气中的低语"

| 项目 | 内容 |
|------|------|
| **性质** | 松散部族联盟 |
| **领地** | 南荒（热带雨林+萨瓦纳草原，纬度0°~23.5°N） |
| **核心能力** | 蛊术（以蛊虫为媒介的独特修行体系） |
| **联盟长** | "万蛊圣母"，宗师境下品（蛊师体系的最高境界称谓） |
| **人口** | 各部落合计约二十万——但能战斗的蛊师不超过500人 |

### 3.1 蛊术与南荒生态

> **来自功法流派体系**：蛊术属于"奇门百家"中的南荒特色——"以蛊虫为媒介"的修行路径。

蛊术不是武学——它更接近一种**生态共生技术**。蛊师与蛊虫之间建立的是共生关系而非主仆关系：

| 蛊术类型 | 手段 | 用途 |
|---------|------|------|
| **控心蛊** | 将蛊虫植入目标体内，操控其行动 | 审问/控制/暗杀 |
| **噬体蛊** | 蛊虫从体内腐蚀目标的经脉和脏腑 | 慢性毒杀——无解 |
| **共生蛊** | 蛊虫与蛊师共享生命力 | 强化蛊师体质——代价是寿命绑定 |
| **母蛊** | 蛊虫之母——控制所有子蛊的核心 | 蛊师最大的秘密和弱点 |

### 3.2 南荒的悲剧

南荒蛮族是第一图层**最被边缘化的群体**。他们拥有毒药和蛊术——但缺少粮食、铁器和盐。他们长期被各方势力利用：

- **朝廷**视他们为"蛮夷"——偶尔征讨，偶尔怀柔
- **中原门派**蔑视蛊术为"邪术"——但暗中购买南荒毒药
- **冥渊教**在南荒传教，利用蛮族百姓作为炮灰
- **盐商**以食盐和铁器换取蛮族的怨灵结晶和毒瘴蛊虫——交换比例极度不公

> **《枪炮、病菌与钢铁》映射**：南荒蛮族是热带雨林环境的囚徒——《The Planet Construction Kit》指出"热带雨林的土壤极其贫瘠"，无法支撑大规模农业→无法产生粮食盈余→无法养活脱产的专家阶级→无法发展出复杂的政治组织。**他们不是"野蛮"——而是被地理环境锁死了发展上限。**

## 四、西域商路城邦 —— "丝路上的绿洲"

| 项目 | 内容 |
|------|------|
| **性质** | 商贸城邦联合体 |
| **位置** | 天柱山脉以西的高原荒漠绿洲带 |
| **核心资源** | 贸易中转——连接西境隐世宗门与中原的商路中间站 |
| **规模** | 大小城邦约十余个，人口合计数万 |

### 核心设定

西域城邦本身武力不强——没有天象境坐镇，最强者不过炼气境巅峰。但他们控制着**天柱山脉西侧唯一可通行的商路**。西境隐世宗门需要通过他们购买中原的粮食和盐，中原需要通过他们获取西境的流光玄砂和灵砂。

这赋予了西域城邦一种奇特的"中间人权力"——他们不强大，但**不可或缺**。

| 主要城邦 | 特色 | 关键 |
|---------|------|------|
| **玉门关** | 最东端，与中原接壤 | 景朝在此设有关卡，是管控东西贸易的咽喉 |
| **楼兰** | 绿洲最大，商贸集散中心 | 各方势力在此设有"商馆"，实际上是情报站 |
| **龟兹** | 最西端，与西境宗门最近 | 衍道宗在此有秘密的"道观"——名为传教，实为研究天柱西坡的异象 |

## 五、异族势力在"暴风前夜"中的态势

> 呼应政治体系总设定第十章："景朝·武安四十七年——暴风前夜"

```
                北疆·苍狼汗国
            ┌── 统一完成，厉兵秣马 ──┐
            │   等待天灾窗口南下     │
            │                       │
   西域城邦 ─┤                       ├── 景朝（衰败中）
  （两面讨好）│                       │ 
            │                       │
            └── 南荒蛊族联盟 ────────┘
                被各方利用，内部不稳
```

**关键变量**：
1. 阿骨烈是否会在天灾来临前就主动南下？（他有这个耐心等，但部下未必）
2. 南荒万蛊圣母是否会与冥渊教彻底决裂？（冥渊教剥削蛮族的手段越来越过分）
3. 西域商路是否会被某一方势力切断？（一旦断绝，西境宗门与中原的平衡将立刻崩塌）

---

> **全章总结**：异族势力是第一图层"棋盘"上的**边缘棋子**——但边缘棋子往往在变局中发挥关键作用。苍狼汗国是悬在中原头顶的铁蹄，南荒蛊族是被所有人忽略的火药桶，西域城邦是连接东西的脆弱纽带。**当三百年周期律终于降临，这些"边缘"势力将成为决定天下归属的胜负手。**
