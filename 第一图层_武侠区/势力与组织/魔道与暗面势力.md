## 一、暗面势力总论

### 1.1 "暗面"的本质

第一图层的暗面势力并非铁板一块，而是一个由**被正道体制排挤者**、**被系统异化者**、**主动挑战规则者**组成的松散生态。他们的共同点只有一个：**不被正道和朝廷的"虚构秩序"所承认。**

> **《人类简史》映射**："任何大规模人类合作的根基，都在于虚构故事。"正道的合法性建立在"天道正统"的虚构之上。那些被这套虚构故事排斥或看穿虚构本质的人，自然就被推到了"暗面"。

### 1.2 暗面势力分类

          │        │        │
      冥渊教      天机楼     "无名"
      血衣侯府    万骨堂     ？

## 二、魔道宗门

### 2.1 冥渊教 —— "吞天噬地"

| 项目 | 内容 |
|------|------|
| **性质** | 魔道·噬魂系 |
| **驻地** | 南荒热带雨林边缘·毒龙潭附近（灵气异常区） |
| **核心禁术** | 噬魂大法——吞噬他人灵魂数据以瞬间提升境界 |
| **教主** | "冥渊教主"，宗师境巅峰（吞噬了至少十七名高手的灵魂） |
| **信众** | 核心修士约200人，外围"信徒"（被洗脑的南荒蛮族）数千 |

#### 起源

冥渊教的创教史是一出悲剧。初代教主"莫无悲"原是一品门派弟子，天赋极高却因出身寒门，在"上品无寒门"的士族垄断体制下始终无法获得核心功法传承。被逐出师门后，他在南荒深渊裂缝附近偶然获取了一卷来历不明的残简——上面记载的正是**噬魂之术的底层原理**。

> **系统真相**：那卷残简并非"上古遗宝"——而是系统代理人故意遗落的**测试脚本碎片**。代理人想测试"灵魂数据强制合并"会产生什么样的极端情感反应。莫无悲和他的追随者们，从一开始就是实验室里的小白鼠。

#### 组织架构

> **《狗头人世界构建指南》**："宗教/邪教的先知'本质上就是对既有秩序的破坏'……新宗教的诞生总是伴随着暴力与狂热。"

```
          冥渊教主（"冥渊至尊"）
           │
    ┌──────┼──────┐
    │      │      │
  魂殿    狱殿    蛊殿
 （修行）  （刑罚/炼魂） （与南荒蛊族合作）
    │
 十八冥使（核心战力，每人至少吞噬过一名炼气境高手）
```

- **魂殿**：修行噬魂大法的核心区。内部按"吞噬级数"排序——吞噬越多，地位越高
- **狱殿**：关押被捕的活人"食材"。同时作为刑罚场所——叛教者会被缓慢剥离灵魂
- **蛊殿**：与南荒蛊族联盟的接口。利用蛊虫控制偏远村落的蛮族，作为教中最外围的炮灰

#### 内外两面性

> **《狗头人》**："一个极其仁慈的社会组织，可能需要精心掩盖其苛刻的内部规则或残忍的献祭仪式。"

冥渊教在南荒并不以"邪教"面目示人。他们在蛮族部落中自称是"解脱者"——宣称通过噬魂可以"超度亡者，令其灵魂归于大道"。蛮族百姓并不知道所谓的"超度"实际上是将活人灵魂喂给冥渊教修士。

#### 叙事价值

冥渊教的真正悲剧在于其**哲学困境**：

> **《庄子》映射**（来自功法体系设定）："魔道修行者的悲剧在于——他们试图用'执念'获取'无己'才能到达的力量。"

噬魂大法的使用者每吞噬一个灵魂，就会在自己的意识中增加一个"声音"。吞噬三人以上后，人格分裂开始不可逆转。冥渊教主已经吞噬了十七人——他体内有十八个灵魂在争夺控制权。**他不是"邪恶的暴君"——他是一个被十八个意识撕裂的疯子，每一个意识都在痛苦地尖叫。**

### 2.2 血衣侯府 —— "铁蹄与血月"

| 项目 | 内容 |
|------|------|
| **性质** | 魔道·血祭系 + 游牧骑兵 |
| **驻地** | 北疆草原深处某废弃古城（地震断裂带附近，灵气忽强忽弱） |
| **核心禁术** | 血祭权柄——以活人鲜血为祭品，短暂召唤远超自身境界的力量 |
| **侯主** | "血衣侯"，宗师境中阶（但血祭后可短暂达到天象境战力） |
| **兵力** | 魔修约150人 + 被裹挟/雇佣的草原骑兵约3000骑 |

#### 起源

血衣侯府的创始人"赫连苍"是苍狼汗国前代大汗的庶子，在汗位争夺中失败后流亡中原。他在北疆断裂带的古战场废墟中偶然发现了一处上古遗迹——遗迹中保存着一套以鲜血为媒介的异常能量调用协议。

> **系统真相**：这套"血祭"本质上是远古时代一名系统代理人测试"灵魂数据强制读写"所遗留的实验接口。血液中的铁分子恰好能作为生物电传导媒介，短暂建立与底层引擎的高带宽连接——但每次调用都会对使用者的灵魂数据造成不可逆损坏。

#### 组织特色

血衣侯府不是传统的"修仙门派"——它更接近一个**军事化的游牧-魔道混合政权**。

```
         血衣侯（侯主，最高统帅）
          │
     ┌────┼────┐
     │    │    │
   祭坛   铁骑   暗哨
  （魔修） （骑兵） （情报）
```

- **祭坛**：核心魔修团队，负责血祭仪式和战场上的"一次性超级增幅"
- **铁骑**：3000草原骑兵。他们不是魔修，只是为了战利品和自由而效力的雇佣兵
- **暗哨**：渗透到北疆各部落和中原边境的探子

> **《君主论》映射**：血衣侯的铁骑就是马基雅维利所警告的"雇佣军"——"雇佣军不团结、包藏野心、毫无纪律可言。他们唯一的动力是微薄的军饷，但这并不足以让他们愿意为你赴死。" 一旦血衣侯在战场上显露败相，3000铁骑会毫不犹豫地抛弃他。

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 苍狼汗国 | 死仇 | 血衣侯是前代大汗庶子，现任大汗视其为篡位威胁 |
| 冥渊教 | 偶尔合作 | 两大魔道各取所需——但互相防备 |
| 景朝北疆边军 | 直接对抗 | 血衣侯劫掠边境，是朝廷心腹大患 |
| 正道门派 | 通缉对象 | 武者监察司悬赏令第三号——仅次于冥渊教主和一名散修魔头 |

## 三、灰色组织

### 3.1 天机楼 —— "天下无不知之事"

| 项目 | 内容 |
|------|------|
| **性质** | 灰色·情报交易与暗杀组织 |
| **总部** | 无固定总部——以"天机分号"分布于各大城池 |
| **创始人** | "天机老人"（身份成谜，从未有人见过其真面目） |
| **规模** | 核心成员约50人，外围线人和合作者数百 |
| **活动范围** | 覆盖中原全境、东海沿岸，北疆和西境有零星据点 |

#### 核心设定

天机楼的商业模式极其简单：**出售情报，承接暗杀。价高者得，不问正邪。**

> **《货币崛起》映射**："每一次重大历史现象背后都隐藏着金融秘密。" 天机楼并不直接参与任何势力的博弈——但它通过信息差来**操纵博弈的走向**。当两个门派即将开战时，天机楼会同时向双方出售"对方的弱点情报"——确保战争发生，并从中牟利。

#### 组织架构

天机楼采用**细胞式结构**——每个分号独立运作，彼此不知对方的位置和人员。只有天机老人知道全貌。

```
         天机老人（身份不详，从未露面）
          │
     ┌────┼────┼────┐
     │    │    │    │
   天字号  地字号  人字号  ...
  （天京） （两河洲）（蜀中） （各地分号）
     │
  ┌──┼──┐
  │  │  │
 探子 杀手 掮客
```

- **探子**：潜伏在各门派、朝廷、商会中的线人。有些人甚至不知道自己在为天机楼工作
- **杀手**：承接暗杀委托。等级从"凡"到"天"分四等——"天"级杀手可猎杀炼气境巅峰
- **掮客**：在各分号坐镇，负责接单、定价、交付情报

#### "天机老人"之谜

> **《狗头人》**："秘不可宣的终极目标——邪教的最高核心知晓'诸神其实比人们所知的更虚弱'……"

天机老人的真实身份是本设定中最大的谜团之一。三种可能性（可在大纲确定后选定）：

| 假说 | 内容 | 叙事价值 |
|------|------|---------|
| **假说A** | 天机老人是系统代理人之一，天机楼是他操控图层的工具 | 最黑暗——整个情报网络都是系统的"耳目" |
| **假说B** | 天机老人是一名半觉醒者，他建立天机楼是为了收集关于"系统真相"的碎片 | 最复杂——天机楼可能是主角的潜在盟友 |
| **假说C** | 天机老人已死百年，天机楼由一套传承制度自动运转 | 最讽刺——一个没有首领的组织，却是天下最大的情报机器 |

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 所有势力 | "客户" | 天机楼对所有愿意付钱的人提供服务 |
| 碧落仙宫 | 竞争 | 两大情报网络争夺信息市场 |
| 景朝暗卫 | 猫鼠游戏 | 暗卫多次试图铲除天机楼，但从未成功定位总部 |
| 衍道宗 | 秘密客户 | 衍道曾向天机楼购买过关于"天道异象"的情报 |

### 3.2 万骨堂 —— "死人不会说谎"

| 项目 | 内容 |
|------|------|
| **性质** | 灰色·雇佣杀手/赏金猎人行会 |
| **总部** | 中原某地下城（具体位置是行业机密） |
| **堂主** | "万骨侯"，宗师境下品 |
| **规模** | 注册赏金猎人约500人，活跃者约200人 |

**核心设定**：万骨堂不同于天机楼的情报路线——它是一个纯粹的**暴力服务提供商**。任何人只要出得起价，就可以在万骨堂发布悬赏缉拿令或暗杀委托。万骨堂本身不执行任务，而是作为**中间平台**，将委托分配给注册的赏金猎人。

> **《君主论》映射**：万骨堂的赏金猎人就是典型的"雇佣军"——"如果他能力卓越，他一定会渴望壮大自己的势力，最终反噬雇主；如果他是个平庸之辈，则会直接在战场上毁了你。" 万骨堂的信誉全靠"完不成任务就退全款"的规矩维持，而非赏金猎人本身的忠诚。

## 四、地下网络

### 4.1 "无名" —— 觉醒者的微光

| 项目 | 内容 |
|------|------|
| **性质** | 极度秘密·反叛者/觉醒者联盟 |
| **总部** | 无总部——以暗号、接头人、秘密集会运作 |
| **核心成员** | 不超过20人（半觉醒者或对"天道"产生根本怀疑者） |
| **影响范围** | 极其有限——但潜在影响力无穷 |

#### 核心设定

"无名"不是一个传统意义上的组织——它更像是一张**由共同的直觉连接起来的隐秘网络**。成员之间甚至不使用固定名号，只以暗号相认。

他们的共同点是：**在不同的经历中，各自隐约感知到了"这个世界有什么不对"。**

成员来源极其多样：

| 成员类型 | 来源 | "觉醒"触发 |
|---------|------|-----------|
| 禅修者 | 某佛门小派 | 在极深的禅定中"听到"了与灵气无关的"底层噪音" |
| 剑修 | 太清剑宗弃徒 | 在剑意突破瞬间触碰到了"法则之墙"的边界 |
| 散修 | 无门无派 | 在古战场禁地中捡到了跨图层数据碎片 |
| 商人 | 东海盐商二子 | 发现某些"天灾"的发生时间与"灵谷种减产"有精确的数学对应关系 |
| 官僚 | 景朝暗卫退役者 | 在执行任务时偶然发现系统代理人的存在痕迹 |

#### 组织原则

> **《狗头人》**："教派必须设计出针对大众的'公众形象'和仅限高层知晓的'核心机密'。"

"无名"没有公众形象——**它的存在本身就是最大的机密**。但内部有三条铁律：

1. **不主动招募**：只有在长期观察后确认对方确实产生了"觉醒"倾向，才会试探性接触
2. **不集中行动**：永远不超过三名成员同时出现在一个地点——防止被一网打尽
3. **真相不外传**：成员之间分享的"觉醒碎片"不得对外泄露——因为目前没有能力保护泄露者

#### 叙事价值

"无名"是为主角预留的**命运交叉点**。当主角的觉醒程度足够深时，他会以某种方式与"无名"建立联系——可能是在某个看似偶然的相遇中，对方说了一句让他脊骨发凉的话：

> "**你有没有想过——为什么每三百年，天灾的发生时间总是那么……'精确'？**"

## 五、魔道散修与魔头

除了有组织的势力外，第一图层还游离着大量"独狼"式的魔道散修。他们大多是被正道门派驱逐或被朝廷追杀的个体，各有各的悲剧故事。

### 当世通缉令（武者监察司）

| 排名 | 代号 | 境界 | 禁术类型 | 特征 |
|------|------|------|---------|------|
| **第一** | 冥渊教主 | 宗师巅峰 | 噬魂 | 吞噬十七人灵魂，十八重人格 |
| **第二** | "枯荣" | 宗师中阶 | 燃命 | 原百草谷弟子——以医入魔，发现了通过燃烧他人寿元治愈绝症的禁术 |
| **第三** | 血衣侯 | 宗师中阶 | 血祭 | 前苍狼汗国王子+3000铁骑 |
| **第四** | "无相" | 宗师下品 | 逆天 | 尝试强行调用系统底层权限的"疯子"——半边身体已被"格式化"为石质 |
| **第五** | "鬼医" | 炼气巅峰 | 噬魂（变体） | 吞噬的不是整个灵魂而是"记忆片段"——他通过窃取记忆来学习一切功法 |

## 六、暗面势力间的生态关系

```
          ┌─────── 互相利用但绝不信任 ───────┐
          │                                   │
       冥渊教 ←── 偶尔交易 ──→ 血衣侯府
          │                         │
          │ 客户                    │ 客户
          ↓                         ↓
       天机楼 ──── 信息中立 ────→ 万骨堂
          │                         │
          │ 不知道对方存在           │ 不知道对方存在
          │                         │
       "无名" ←── 完全隔绝 ──→ 各散修魔头
```

> **底层真相**：系统代理人对魔道的态度是**有限度的容忍**。魔道的存在为正道提供了一个永恒的"敌人"——这让正道门派始终保持警觉、投入资源训练弟子、定期发动"讨魔"战争——所有这些都是优质的情感数据源。**只要魔道不威胁到图层的底层稳定，代理人不会真正消灭他们。**

---

> **全章总结**：暗面势力是第一图层这出大戏中**不可或缺的"反派"角色**——但"反派"的标签是正道叙事强加的。冥渊教主的疯狂源于对不公体制的绝望，血衣侯的暴虐源于王位争斗中的失败，"无名"的隐秘源于对真相的恐惧。**在系统的剧本里，正邪双方都是演员——唯一的区别是，暗面势力中有极少数人，开始隐约意识到自己是在演戏。**
