## 一、正道门派体系总论

### 1.1 何谓"正道"

"正道"并非道德判断，而是一种**政治标签**——凡是向朝廷武者监察司备案、遵守江湖公约、不修炼禁忌功法名录上功法的门派，统称"正道"。

> **底层真相**：正道与魔道的区分，本质上是系统通过代理人培育的一种"虚构的二元对立"——正如《人类简史》所言，"任何大规模人类合作的根基，都在于某种只存在于集体想象中的虚构故事"。正邪之分给了门派弟子一个简单的"我们vs他们"的认知框架，从而最大化门派间的冲突烈度和情感数据产出。

### 1.2 门派四要素

参照《狗头人世界构建指南》，一个成熟门派必须具备四个基础要素：

| 要素 | 对应 | 作用 |
|------|------|------|
| **等级制度** | 掌门→长老→嫡传→内门→外门→记名 | 确保权力传递与资源分配的秩序 |
| **超越性目标** | 远大于任何个人目标的门派愿景 | 确保创始人陨落后门派依然存续 |
| **历史与传说** | 门派起源神话、历代先贤事迹 | 建构"虚构的故事"以凝聚数千弟子 |
| **领导者** | 坐镇高手的境界与威望 | 核心武力=一切秩序的最终保障 |

### 1.3 内外环保密机制

> **《狗头人世界构建指南》**："任何人都可以加入，但不是所有人都能进入高层，因为一个社会很可能分为内环和外环。内环掌握着社会真正的目标……"

每个顶级门派都有**三层真相**：

```
外层（外门弟子/江湖人皆知）：
  → "我派奉天道，斩妖除魔，护佑苍生"

中层（内门弟子/嫡传知晓）：
  → 门派真正的利益诉求、战略部署、与其他势力的暗中交易

内层（掌门/极少数长老）：
  → 关于"天道"与系统的朦胧感知碎片（历代先贤留下的隐秘笔记）
  → 门派立足之洞天福地的真正秘密
```

## 二、超品门派（天象境坐镇，全图3-5个）

### 2.1 太清剑宗 —— "一剑问天"

| 项目 | 内容 |
|------|------|
| **等级** | 超品第一 |
| **流派** | 剑道超然 |
| **驻地** | 天柱山脉·太清峰洞天（海拔4000m+，全图层灵气浓郁区） |
| **核心资源** | 苍雷锂玉（铸造灵剑的雷系极品材料）、化劫铅晶（雷泽禁地产出） |
| **开派时间** | 约1900年前（封锁纪末期） |
| **弟子规模** | 嫡传30余人，内门约300人，外门约2000人，记名弟子数千 |

#### 超越性目标

"问天"——追求剑道的终极：以剑破碎虚空。

太清剑宗的创派祖师"玄清真人"是有记载以来第二位触碰天象境的人类。他登临太清峰时曾以一剑劈开山壁，留下"吾问天道而天不语，遂以剑代问"的刻铭。这句话构成了太清剑宗两千年来的精神内核——**以剑叩问天道的终极答案**。

> **系统真相**：历代太清掌门中，最接近真相的是第七代掌门"无名道人"。他在观想太清峰底部洞天时曾留下一句隐晦笔记："大道非道，剑锋所触，似有壁垒，非石非气，乃**法则之墙**。" 这段话被门派视为偶像发疯时的呓语，但实际上他触碰到了图层物理引擎的边界。

#### 内部架构

```
              剑首（掌门，天象境）
               │
        ┌──────┼──────┐
        │      │      │
     太清阁   问天阁   斩邪阁
    （修行）  （悟道）  （外事/战斗）
        │      │      │
    嫡传弟子  闭关长老  执法/缉拿
    （修剑）  （参悟大道）（对外任务）
```

- **太清阁**：修行主体。弟子按境界分为九层剑台，逐层晋升
- **问天阁**：研究剑道极致的闭关长老团。阁内保存历代掌门的"悟道笔记"——门派最高机密
- **斩邪阁**：对外事务。负责门派的江湖交往、与朝廷对接、讨伐魔道

#### 门规铁律

1. **一剑一生**：入门后终身只使一柄灵剑，人剑合一。弃剑者即弃道
2. **不入朝堂**：太清弟子不得出仕为官。可受邀协助朝廷，但不可受封
3. **剑不伐无罪**：出剑必有正当理由。滥杀者逐出师门，由斩邪阁追杀
4. **悟道笔记不外传**：问天阁的历代笔记是太清最高机密。泄露者灭口

#### 门派性格与叙事定位

太清剑宗是正道的**精神领袖**——清高、超然、不染俗尘。但这种清高也意味着他们对底层百姓的苦难**视而不见**。他们追求的是剑道极致，而非天下太平。

> **《君主论》映射**：太清剑宗犯了马基雅维利所警告的"中立之过"——"优柔寡断的君主，为了逃避当前的危险，往往采取中立的道路，因而往往走向灭亡。"太清长期避世不出，在即将来临的天下大乱中可能成为最先被正邪双方同时要求站队的对象。

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 衍道宗 | 亦敌亦友 | 学术分歧——太清以剑入道，衍道以理入道。双方争论千年 |
| 伏虎禅院 | 淡漠 | 禅院亲朝廷，太清不入朝堂。理念不合但无直接冲突 |
| 景朝朝廷 | 名义尊重 | 朝廷不敢得罪天象境坐镇的门派，太清也给朝廷面子 |
| 天机楼 | 警惕 | 太清怀疑天机楼收集了问天阁悟道笔记的部分内容 |

### 2.2 衍道宗 —— "万法归一"

| 项目 | 内容 |
|------|------|
| **等级** | 超品第二 |
| **流派** | 内家正宗（八卦系为主，兼修太极/形意） |
| **驻地** | 天柱山脉中段·紫霞洞天（海拔3000m，云海环绕） |
| **核心资源** | 流光玄砂（冰川干涸灵脉沉淀物，修行核心辅料） |
| **开派时间** | 约2500年前（仙人纪末期，全图层最古老的门派之一） |
| **弟子规模** | 嫡传弟子极少（不超过12人），内门约200人，外门记名约1500人 |

#### 超越性目标

"衍道"——推演大道的终极形态。

衍道宗的开派祖师"衍天子"是仙人纪末期第一批突破宗师境的人类。他创建门派的目的不是征战天下，而是**建立一个专门研究"天道法则"的学术组织**。历代弟子将对天地运行规律的感悟编纂成册，称为《衍道全书》——这是第一图层最接近"自然科学"的文献，尽管其中大部分结论是错误的，但里面隐藏着对系统底层代码的朦胧直觉。

> **系统真相**：《衍道全书》第三十七卷·"天地运行之谬"中记载了一个奇特的观察——"每逢月圆之夜，紫霞洞天深处的'道源石'表面会浮现**流动的纹路**，其规律似与天象无关，反与**某种不可知的计算法则**暗合。"——道源石实际上是洞天福地底层的数据中继站残骸暴露出的接口面板。

#### 内部架构

衍道宗不设传统的堂口/殿阁，而是按**学术方向**分为"三道"：

```
              宗主（天象境，"道尊"尊号）
               │
        ┌──────┼──────┐
        │      │      │
      天道院   地道院   人道院
    （天文/气象） （地理/地脉） （人体/经脉）
        │      │      │
    研究天象   研究地脉   研究武道
    与灵气潮汐  与风水法则  与境界突破
```

- **天道院**：研究天象变化、灵气潮汐与气候的关联——他们是第一图层最杰出的天文学家和气象学家
- **地道院**：研究地脉走向、风水法则、洞天福地的运行规律——在所有门派中对龙脉理解最深
- **人道院**：研究人体经脉、武道境界突破的底层机制——功法设计的理论大师

#### 门规铁律

1. **求道不争锋**：衍道弟子不主动挑战他人。但自卫可不留手
2. **知无不录**：一切观察、感悟必须记入《衍道全书》。私藏知识者逐出师门
3. **嫡传限十二**：嫡传弟子永远不超过十二人——对应十二时辰，是"天道运行的刻度"
4. **道源石不可触**：紫霞洞天最深处的"道源石"，只有宗主一人有权接近

#### 门派性格与叙事定位

衍道宗是正道中的**学者型门派**——他们对战斗兴趣不大，对知识的渴求才是驱动力。然而，正因为他们是最接近系统真相的门派，他们也是**系统代理人最密切监控的对象**。

> **《人类简史》映射**：衍道宗的弟子试图用理性和观察去理解"天道"——但他们不知道自己试图理解的"天道"本身就是一套虚构的规则框架。他们的学术努力越深入，就越危险——因为他们可能无意中碰到真相，而代理人绝不会允许这种事发生。

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 太清剑宗 | 亦敌亦友 | 学术争论——衍道认为太清"以力问道"是蛮夫行径 |
| 青城隐派 | 深度合作 | 青城在蜀中的异常发现常与衍道分享，双方暗中交流 |
| 天道教 | 强烈敌意 | 天道教宣扬的"天启"与衍道的理性推演根本冲突 |
| 系统代理人 | 被暗中监控 | 代理人曾至少三次暗中干预衍道的研究方向 |

### 2.3 伏虎禅院 —— "佛拳镇山河"

| 项目 | 内容 |
|------|------|
| **等级** | 超品第三 |
| **流派** | 外家刚猛 + 佛门禅武 |
| **驻地** | 中原名山·龙门山洞天（中原腹地，海拔1200m，灵气充裕） |
| **核心资源** | 山脚良田数千顷（息渊土产区）+ 龙门山灵泉（天然药浴修行辅助） |
| **开派时间** | 约1600年前（诸国纪初期） |
| **弟子规模** | 武僧800余人，文僧（管理寺产/佛学/医术）约400人，俗家弟子数千 |

#### 超越性目标

"伏虎"——以佛法伏世间之虎，以拳法镇天下之乱。

伏虎禅院的创建与一场上古浩劫直接相关：诸国纪初期，中原陷入群雄割据的大乱世，饿殍遍野、人相食。一名游方僧人"渡厄大师"以一己之力平息了龙门山周围数百里的战乱，收容难民于山中，开荒种田、传授拳法自卫。他留下的遗训是："**不入红尘，何知苦海？不握铁拳，何以渡人？**" 伏虎禅院因此成为正道中**最入世**的超品门派。

#### 内部架构

```
              方丈（天象境，"大觉"法号）
               │
        ┌──────┼──────┼──────┐
        │      │      │      │
     罗汉堂   般若堂   戒律院   济世堂
    （武僧）  （佛学/悟道）（内部执法）（对外慈善）
```

- **罗汉堂**：武僧修行。分为外罗汉（外家刚猛）和内罗汉（禅定入道，转修内家）
- **般若堂**：佛学研究。与衍道宗的"学术性"不同，般若堂追求的是**顿悟**而非推演
- **戒律院**：极其严苛的内部律法执行机构。武僧犯戒，轻者面壁十年，重者废去修为逐出佛门
- **济世堂**：管理寺产、施粥赈灾、免费医疗。这是伏虎禅院在民间声望极高的核心原因

#### 门规铁律

1. **出家不娶**：武僧与文僧均须剃度，终身不婚（俗家弟子例外）
2. **不杀无辜**：出手可伤不可杀——除非对方是罪大恶极的通缉犯或魔道修士
3. **不蓄私财**：一切财物归寺院公有。长老不得拥有超过三件法器
4. **逢灾必出**：凡天灾人祸，禅院必须第一时间派僧救援。这是渡厄大师的遗训

#### 门派性格与叙事定位

伏虎禅院是正道的**行动派**——他们不像太清那样清高出世，也不像衍道那样埋头研究。他们直接介入世事，赈灾、调停纠纷、震慑魔道。但这也意味着他们**与朝廷的关系极深**——龙门山位于中原腹地，背靠朝廷粮仓，经济上高度依赖朝廷的息渊土供应。

> **《枪炮、病菌与钢铁》映射**：伏虎禅院是门派中的"农耕帝国"——他们有土地、有粮食、有人口基数——但也因此被束缚在龙门山。不像太清和衍道可以在天柱高原的严酷环境中遗世独立，伏虎一旦失去中原腹地的粮食供应，数千弟子将无以为继。**这是他们不得不亲近朝廷的根本原因。**

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 景朝朝廷 | 密切合作 | 朝廷赐田+减免赋税，禅院为朝廷镇守中原、安抚民心 |
| 武者监察司 | 良好 | 禅院多次协助监察司剿灭中原魔道据点 |
| 太清剑宗 | 互相尊敬 | 佛道无争——但方丈内心认为太清"避世独善"有违大道 |
| 天河漕帮 | 复杂 | 漕帮控制天河航运，禅院的物资运输依赖漕帮 |

## 三、一品门派（多名宗师境坐镇，全图10-20个）

### 3.1 青城隐派 —— "大隐于蜀"

| 项目 | 内容 |
|------|------|
| **等级** | 一品（隐世特殊） |
| **流派** | 内家正宗（太极系） |
| **驻地** | 蜀中盆地·青城洞天 |
| **核心资源** | 天蚕丝（灵器编织材料）、蜀中药材 |
| **特殊地位** | 长期不参加武林大会，不向监察司报备全部底细 |

**核心设定**：青城隐派选择蜀中绝非偶然。蜀中盆地"四面环山，天然屏蔽了外界的系统监控信号"（地理总设定V3）。青城掌门代代相传一个秘密：**在青城洞天最深处，存在一种被他们称为"天暝"的周期性现象——每隔六十年，洞天内的灵气会骤然消失约一炷香的时间，万籁俱寂，如同整个世界被"关闭"了一瞬。** 这实际上是蜀中洞天底层数据中继站进行例行维护重启时的表现。

青城掌门将此现象记录在《天暝录》中，但从不对外公开。他们隐约知道"天道"并非不可动摇的——但他们选择了**沉默与隐忍**，而非像衍道宗那样公开研究。

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 衍道宗 | 秘密合作 | 《天暝录》的部分内容与衍道的《衍道全书》交叉验证 |
| 景朝朝廷 | 疏远 | 蜀中地形天然隔绝，朝廷鞭长莫及 |
| "无名"组织 | 潜在关联 | 青城内部可能有半觉醒者加入了"无名" |

### 3.2 碧落仙宫 —— "海上天宫"

| 项目 | 内容 |
|------|------|
| **等级** | 一品 |
| **流派** | 剑道 + 奇门（机关术/通讯术） |
| **驻地** | 东海·碧落岛洞天（火山岛链上的灵气充裕之地） |
| **核心资源** | 黑曜磁髓（铸造灵器）、通音海螺（远程通讯） |
| **特殊能力** | 掌握全图层最发达的**远程通讯网络**——通音海螺网 |

**核心设定**：碧落仙宫表面上是一个与世隔绝的海上剑修门派，实际上它凭借通音海螺网络控制着东海的情报命脉。碧落的"仙使"分布在中原各大城池，表面上售卖通音海螺通讯服务，实际上**所有经由海螺网络传递的信息都被碧落截获备份**。

> **《货币崛起》映射**：碧落仙宫如同修仙界的"罗斯柴尔德家族"——他们掌握的不是金钱，而是**信息**。"处理数额巨大的股票，创办公司……从而轻易控制国家政策"——碧落虽不直接打仗，但他们能通过提前获知各方动向来操纵局势。

#### 势力关系

| 对象 | 关系 | 原因 |
|------|------|------|
| 东海盐商 | 深度绑定 | 碧落保护盐商航线，盐商提供经济资助 |
| 天机楼 | 竞争 | 两大情报网络的直接竞争对手 |

## 五、正道门派间的结构性矛盾

### 5.1 "武林盟主"的虚与实

名义上，正道门派在面对重大威胁时会推举"武林盟主"统一号令。实际上：

- 超品门派不会服从盟主——盟主通常是一品门派的掌门，修为不足以号令天象境
- 盟主更像是一个"外交代言人"，而非真正的统帅
- 历史上唯一一次盟主真正统一了正道行动，是永安朝铁剑侯——他本人是天象境，后来直接建立了王朝

> **《君主论》映射**：马基雅维利认为"联盟军比雇佣军更致命——因为他们是作为整体听命于外国君主的。" 正道联盟的本质问题就在于此——每个门派都是一支听命于各自掌门的独立军队，"盟主"不过是一个礼仪性头衔。

### 5.2 "差异化"驱动的内部竞争

> **《幻想世界构建练习册》**："许多相邻的国家和文化通过'差异化'概念将自己与邻国区分开来……故意做相反的事情以彰显不同。"

太清崇剑、衍道崇理、伏虎崇拳——三大超品的分歧不仅是功法路线之争，更是**身份认同**之争。每个门派都通过"我与其他门派不同"来定义自我。这种差异化在平时是健康的学术竞争，在危机时刻却可能阻碍联合。

### 5.3 150人悖论

> **《人类简史》**："只要超过150人，大多数人就无法真正深入了解所有成员。"

小门派靠师徒情谊维系，但超品门派拥有数千弟子。这意味着：
- **绝大多数弟子永远不会见到掌门和长老**——他们的忠诚建立在"虚构的故事"上
- 一旦门派信仰体系被动摇（比如真相被揭露），数千弟子的联合将瞬间瓦解
- **主角如果要对抗整个门派体系，最有效的武器不是更强的武力，而是真相**

---

> **本章总结**：正道门派看似团结一致，实际上是一群被资源和身份认同驱动的利益集团。他们共享一套"正道"的虚构叙事，但在利益面前随时可能翻脸。**真正维持正道联盟的不是信仰，而是共同的敌人（魔道）和共同的恐惧（天灾）。一旦这两个外部压力消失，正道必将内战。**
