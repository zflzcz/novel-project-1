# 第一图层·自然资源详录

> 所属：第一图层（古典农耕 / 武侠区）
> 理论基础：《Material World: A Substantial Story of Our Past and Future》（Ed Conway）
> 核心思想：**材料决定文明的形态。** 每一种关键材料的开采、加工和分配，都会催生出特定的社会阶层、贸易路线和战争形态。
> 关联文档：[自然世界设定](自然世界设定.md) · [第一图层总览](../第一图层总览.md)
> 状态：V1.0

---

## 设计原则

《Material World》 揭示了一个核心规律：**文明的每一次飞跃，都源于对某种新材料的掌握。** 石器时代→青铜时代→铁器时代→工业时代，推动变革的不是思想，而是材料。

第一图层（武侠区）作为一个被锁定在"古典农耕+冷兵器"阶段的虚拟世界，其文明发展被系统刻意压制在"前工业革命"阶段。但这并不意味着资源是简单的——恰恰相反，系统通过设计丰富多样的自然资源，来制造无穷无尽的争端和情感波动。

以下资源分为 **三个层级**：

- **基础层（生存级）**：没有它，国家会崩溃、百姓会饿死
- **战略层（争霸级）**：谁掌握它，谁就能征服邻国或称霸江湖
- **超凡层（破界级）**：改写武学极限、触碰系统底层的禁忌之物

## 一、基础层资源（生存级）

### 1. 息渊土（超级沃土）

> **现实映射**：Material World 中的"肥沃土壤/氮肥"——农业的绝对底线

| 属性 | 详情 |
| --- | --- |
| **表象** | 微微泛青光的奇异土壤，混入田地即可无视天灾丰产 |
| **产地** | 天河/玄水中下游冲积平原（参见自然世界设定§五） |
| **用途** | 粮食生产的唯一保障；含量高的稻米还带有微弱的养气功效 |
| **掌控者** | 皇朝户部、中原各州府 |
| **底层代码** | `Biome_Rapid_Render_Cache`（环境生态快速渲染缓存） |

### 2. 食盐（井盐 / 岩盐 / 海凝盐晶）

> **现实映射**：Material World 将盐视为"文明的第一种化学品"——保存食物、维系军队、征收赋税

| 属性 | 详情 |
| --- | --- |
| **表象** | 按纯度分为内陆劣质粗盐（苦涩发黄）和东海极品海盐（剔透雪白） |
| **产地** | **内陆井盐/池盐**：蜀中盆地的深地盐井（内陆最大产盐区）、中原河东盐池；**边疆岩盐**：西境高原与北疆盐碱湖；**极品海盐（海凝盐晶）**：东海归墟联盟控制的“系统Bug海区” |
| **用途** | 食物保存（腌肉/腌鱼是边军防线的命脉）、炼丹主辅料、皮革鞣制、伤口消毒 |
| **地缘影响** | 朝廷实施**盐铁专营**发行盐引。但内陆盐产出受限且质劣，导致中原朝廷乃至武林都高度依赖四大盐商从东海暗中走私的**海凝盐晶**。这种“劣盐掩护好盐”的走私网络，造就了归墟联盟寡头，成为吸取景朝国库血液的最大漏斗。 |
| **底层代码** | `Preservation_Buffer`（数据保鲜缓冲区）——延缓有机数据包的衰变速率 |

### 3. 木材（建筑与燃料）

> **现实映射**：Material World 论述了木材作为人类第一种建筑材料的文明意义

| 属性 | 详情 |
| --- | --- |
| **表象** | 普通林木（松/杉/楠），以及少量特殊巨木 |
| **产地** | 南荒北缘的亚热带森林、中原丘陵区、天柱山脉东坡（迎风坡降水充足） |
| **用途** | 建筑（城池、宫殿、战船）、燃料（冶铁/冬季取暖）、兵器杆柄 |
| **地缘影响** | 北疆的游牧民族几乎**完全缺乏木材**——这是他们无法建造城池和战船的根本原因。中原砍伐过度会导致水土流失→天河泛滥成灾 |
| **底层代码** | `Structure_Mesh_Template`（结构模型模板）——最基础的物理实体搭建框架 |

### 4. 陶土与石材

> **现实映射**：Material World 中的"沙与混凝土"——建设一切的物理基础

| 属性 | 详情 |
| --- | --- |
| **表象** | 各色黏土（制陶、制砖）和天然石材（花岗岩、大理石用于宫殿和墓葬） |
| **产地** | 中原遍地皆有（低价值资源），上等石材集中在天柱山脉东麓 |
| **用途** | 砖瓦城墙、陶器（日用品与储水）、碑碣墓葬。**高温窑变陶**是一种罕见工艺，能接近劫灰铁的硬度 |
| **底层代码** | `Static_Collision_Volume`（静态碰撞体积）——基础物理碰撞壳 |

## 二、战略层资源（争霸级）

### 5. 劫灰铁 / 炎髓（超级铁矿）

> **现实映射**：Material World 中的"铁与钢"——战争形态的决定者

| 属性 | 详情 |
| --- | --- |
| **表象** | 赤红色矿石，深埋于地震断裂带和活火山区 |
| **产地** | 北疆-中原地震走廊，以及北疆深处的火山群 |
| **用途** | 打造无坚不摧的兵器铠甲、攻城器械核心构件、镇国重器的骨架 |
| **地缘影响** | 北方游牧帝国垄断最大矿脉→铁骑横扫→中原被迫以粮换铁或以名门高手交换 |
| **底层代码** | `Physical_Collision_Override`（物理碰撞重写权限） |

### 6. 铜矿与锡矿（青铜合金）

> **现实映射**：Material World 的"铜与青铜时代"——文明的第一次军事革命

| 属性 | 详情 |
| --- | --- |
| **表象** | 绿锈色铜矿和银灰色锡矿，需要混合冶炼 |
| **产地** | 铜矿散布于中原南部丘陵和南荒北缘；锡矿极其稀少，主要产于东海群岛中的某几座火山岛 |
| **用途** | 青铜器皿（礼器、钟鼎→象征皇权正统）、中低端兵器、铜钱铸造（**货币命脉**） |
| **地缘影响** | 铜和锡产地分离→必须贸易才能获得青铜→催生了中原-东海的海上商路。谁控制了锡矿岛，谁就掐住了天下铸币的咽喉 |
| **底层代码** | `Conductivity_Bridge`（导能桥接节点）——青铜器在系统层面具有微弱的能量导通特性，这就是"上古青铜器可降妖"传说的真实来源 |

### 7. 浮光影木（通信材料）

> **现实映射**：Material World 中的"硅与光纤"——信息传输革命

| 属性 | 详情 |
| --- | --- |
| **表象** | 生长在东海高山雪线以上的半透明木材，折断母子枝后可跨距离传声传字 |
| **产地** | 东海群岛的高山（海拔极高、终年云雾笼罩） |
| **用途** | 军事情报网络、皇家密旨传递、门派间联络。是古典世界的"即时通信基础设施" |
| **地缘影响** | 东海海商/海盗集团因垄断此资源，成为所有势力都无法得罪的"中立商人"。皇朝和门派争相下重金求购 |
| **底层代码** | `Quantum_Entanglement_Node`（量子纠缠通信节点） |

### 8. 玄蚕丝 / 蛟筋（高级纺织与弓弦材料）

> **现实映射**：Material World 中的"纤维与纺织品"——贸易和奢侈品的源头

| 属性 | 详情 |
| --- | --- |
| **表象** | 南荒密林中某种巨型蚕虫吐出的漆黑色丝线，以及深水蛟龙的筋腱 |
| **产地** | 南荒雨林（玄蚕丝）、东海深水区（蛟筋） |
| **用途** | 玄蚕丝制成的"暗衣"可劈刀挡箭（轻型软甲）、蛟筋制成的弓弦射程是普通弓的三倍。同时也是顶级内功高手的束脉带（辅助引导内力） |
| **地缘影响** | 南荒蛮族以物易物的核心商品。中原商队为获取玄蚕丝，必须冒着瘴气和蛮族袭击的风险深入南荒→催生了武装商帮和镖局 |
| **底层代码** | `Tensile_Strength_Modifier`（材质拉伸强度修正因子）——系统赋予了这类生物性材料远超物理极限的柔韧度参数 |

### 9. 火油 / 地火（石油替代物）

> **现实映射**：Material World 的核心章节——"石油"，驱动工业化的黑色血液

| 属性 | 详情 |
| --- | --- |
| **表象** | 从特定地层裂缝中自然渗出的黑色粘稠液体，遇火即燃，极难扑灭 |
| **产地** | 北疆西部的戈壁油泉、中原某些古战场的地裂（战争破坏了地层封盖） |
| **用途** | 攻城战的终极武器（火攻/火箭/火油弹）、信号火、冬季取暖燃料（北疆战略物资）。**注意：系统刻意压制了凡人对火油的深度利用（如蒸馏提纯），防止科技树向蒸汽机方向突破** |
| **地缘影响** | 拥有大量火油储备的势力在攻城战中占据压倒性优势。历史上多次"火烧连营"的惨剧都是因为火油的使用 |
| **底层代码** | `Exothermic_Reaction_Amplifier`（放热反应增幅器）——该数据包的化学模拟参数被系统特意调高了燃烧效率 |

### 10. 水银 / 朱砂（丹药与炼金基础）

> **现实映射**：Material World 提到的"汞与早期化学"——炼金术的物质基础

| 属性 | 详情 |
| --- | --- |
| **表象** | 深红色朱砂矿石和从中提炼出的银色液态金属 |
| **产地** | 西境天柱山脉的特定矿洞、南荒某些火山口附近 |
| **用途** | 炼丹的基础材料（几乎所有丹药配方都需要朱砂为引）、防腐（帝王陵墓）、道门画符用的仙砂、毒药（朱砂过量即为剧毒） |
| **地缘影响** | 道门仙宗因掌控朱砂矿脉而成为炼丹术的绝对权威。皇帝为追求长生不老大量征购朱砂→道门与皇权之间形成了深层利益纽带 |
| **底层代码** | `State_Transition_Catalyst`（状态转换催化剂）——在系统层面，朱砂可以作为媒介，加速其他数据包之间的属性重组 |

## 四、资源流通与贸易路线

所有这些资源**不均匀分布**在五大地理区，迫使势力之间必须贸易或战争：

```
                    极北冰原
                   [蚀空水]
                      ↓
        ┌─── 北疆 ───┐
        │ [劫灰铁]   │
        │ [火油]     │
        │ [岩盐]     │
        └──┬─────┬───┘
           │     │
    西境 ──┤  中原  ├── 东海
  [灵砂]   │ [息渊土] │ [浮光影木]
  [朱砂]   │ [陶石]   │ [锡矿]
  [长生泉] │ [铜矿]   │ [须弥石]
           │ [木材]   │ [蛟筋]
           └──┬───────┘
              │
           南荒
         [气血草]
         [玄蚕丝]
         [木材]
```

### 核心贸易路线

| 路线 | 交换内容 | 叙事价值 |
| --- | --- | --- |
| **北路（盐铁互市）** | 中原以粮换北疆的劫灰铁 | 和平时期的经济命脉；一旦断绝必引发南侵 |
| **东路（海上丝路）** | 中原以铜锭换东海的锡矿和浮光影木 | 海商集团的崛起；海盗对贸易线的劫掠 |
| **南路（瘴道商帮）** | 中原以盐和青铜器换南荒的玄蚕丝和气血草 | 武装商帮/镖局的存在基础；蛮族与中原的爱恨交织 |
| **西路（朝圣之路）** | 门派向朝廷输送高手/道门向皇室供奉丹药，换取粮食和护矿权 | 武林与庙堂的利益纽带 |

## 五、资源与文明阶段的锁定

> **系统最阴险的设计**：第一图层的科技树被刻意截断。

某些资源的"深度利用"被系统的底层规则所禁止：

| 被压制的方向 | 涉及资源 | 系统干预方式 |
| --- | --- | --- |
| 蒸汽机 / 内燃机 | 火油 | 火油的蒸馏提纯实验必然"意外爆炸"——系统强制触发失败概率=100% |
| 火药武器 | 硝石/硫磺 | 大规模火药配方的发现者必然"走火入魔暴毙"或"天降雷劫" |
| 远洋航海 | 木材/指南针 | 超过一定距离的航行会遭遇"不可解释的风暴"——系统边界的物理围栏 |
| 印刷术普及 | 纸/墨 | 活字印刷可以存在，但大规模传播"禁忌知识"的书籍会导致"焚书天火" |

> **叙事核心**：这种压制本身就是第一图层最大的悲剧之一——无数天才发明家在"意外"中化为灰烬，而他们永远不会知道，杀死他们的不是命运，而是头顶那片"天"的一行代码。
