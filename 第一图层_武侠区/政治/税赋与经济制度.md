## 二、税制演变——从均田到两税

### 2.1 历代税制

| 朝代 | 税制 | 核心逻辑 | 优点 | 致命缺陷 |
|------|------|---------|------|---------|
| **承天朝** | 均田制 | 按人头授田，按人头纳税 | 初期公平 | 人口增长后无田可授→制度崩溃 |
| **明河朝** | 商税为主 | 盐铁专卖+海贸关税 | 财政充裕 | 武林几乎不纳税→贫富差距极端 |
| **天元朝** | 贡赋制 | 游牧传统——各部向大汗献贡 | 简单直接 | 中原农耕区受不了随意摊派 |
| **永安朝** | 两税法 | 按资产和土地纳税 | 理论公平 | 实际助长土地兼并——越富越买地，越买地越少税 |
| **景朝** | 两税法改良+门派岁贡 | 两税法基础上向门派征灵砂/药材 | 首次将武林纳入税制 | 超品门派的"岁贡"远低于实际财力 |

### 2.2 景朝的"两税法改良"

**税种分类**：

| 税种 | 征收对象 | 税率 | 用途 |
|------|---------|------|------|
| **田赋** | 所有土地持有者 | 田产价值的~5-10% | 军饷+官俸+朝廷运转 |
| **丁税** | 16-60岁成年男性 | 固定额度 | 地方基础设施 |
| **商税** | 商铺、市集交易 | 交易额的~3-5% | 朝廷直入 |
| **盐铁专卖** | 朝廷垄断盐铁生产销售 | — | 朝廷最大单一收入来源 |
| **门派岁贡** | 一品以上门派 | 按等级定额灵砂/药材 | 充入国库用于禁军修行 |
| **关税** | 东海海贸+各道关卡 | ~5-8% | 朝廷+地方分成 |

### 2.3 税制的掠夺性（参照《中国官僚政治研究》）

理论上的税率看起来温和——但实际税负远高于账面：

```
正式税额（5-10%）
    ↓ 加征
地方附加税（"火耗""漕粮折银"等）→ +3-5%
    ↓ 加征
非正式摊派（"陋规""部费"）→ +5-10%
    ↓ 加征
差役劳动（修路/运粮/兵役）→ 无形成本极高
    ↓
实际税负 = 名义税率的 3-5 倍
```

**掠夺链条**：
1. 知县需要向知府行贿以求好评→"部费"
2. 知府需要向巡抚行贿以求升迁→"陋规"
3. 巡抚需要向京官行贿以求不被弹劾→"冰敬""碳敬"
4. 一切成本最终摊派到**最底层的农民身上**

> **底层逻辑**：这套掠夺体系在系统视角下是一台精密的**"苦难放大器"**——层层盘剥确保了底层民众永远处于半饥半饱的状态，产出持续的焦虑和愤怒。而当三百年周期律触发天灾时，这些积压的苦难将如洪水决堤般爆发——产出系统所需的**高烈度情感数据**。

## 三、三大基石资源的政治经济学

### 3.1 息渊土——谁有粮谁为王

| 属性 | 内容 |
|------|------|
| **本质** | 系统算力冗余凝结成的超级土壤矿物 |
| **功能** | 混入普通土壤后可使产量提升数倍，且抗旱抗涝 |
| **产地** | 中原天河中下游冲积平原（主要）、蜀中盆地（次要） |
| **储量** | 正在衰退——矿脉枯竭迹象明显 |

**政治影响**：
- 朝廷将主要息渊土矿脉划为"皇田"直接管控——这是皇权的经济根基
- 士族门阀通过土地兼并间接获得含灵谷种的优质农田
- 息渊土减产=粮食危机=民变——这是三百年周期律的经济触发器

### 3.2 劫灰铁/炎髓——军工命脉

| 属性 | 内容 |
|------|------|
| **本质** | 板块碰撞产生的高密度矿物，蕴含微量灵气 |
| **功能** | 锻造精钢级以上兵器和重甲的必备材料 |
| **产地** | 天柱山脉北段-中原交界的地震断裂带走廊 |
| **政治敏感性** | 极高——产地恰好在北疆-中原交界 |

**政治影响**：
- 控制劫灰铁矿=控制军事制高点
- 长城防线的存在部分原因是**保护断裂带走廊的劫灰铁矿脉**
- 游牧势力每次南下的首要目标之一就是夺取铁矿
- 边镇藩将因掌控就近的矿脉而逐渐拥兵自重——形成"藩镇割据"的隐患

### 3.3 先天灵砂——武学的血液

| 属性 | 内容 |
|------|------|
| **本质** | 灵气高度凝缩的结晶体 |
| **功能** | 突破修行瓶颈、淬炼灵器、批量培训二流以上高手的必需品 |
| **产地** | 西境高原洞天福地深处 |
| **控制者** | 超品门派几乎完全垄断 |

**政治影响**：
- 门派的话语权建立在灵砂垄断之上——没有灵砂就无法培养高手
- 朝廷多次试图介入灵砂开采均以失败告终——矿脉在门派控制的洞天福地内部
- 灵砂黑市是朝廷与门派之间最敏感的灰色地带

### 3.4 制衡公式

```
    朝廷 ← 有粮(息渊土)+有铁(劫灰铁) → 养百万大军
      │                                      │
      │   但缺绝顶高手                        │
      │                                      │
      ↕   交换：高手←→粮铁                    ↕
      │                                      │
      │   但缺粮缺铁                          │
      │                                      │
    门派 ← 有灵砂(先天灵砂) → 培养天象境高手
```

**任何一方垄断三者→必引发另两方联合对抗→系统确保永远无绝对霸权。**

## 四、盐铁专卖——朝廷的经济核武器

### 4.1 景朝盐铁制度

| 品类 | 管控方式 | 年产值（估） | 利润分配 |
|------|---------|------------|---------|
| **海凝盐晶** | 朝廷设盐运使，颁发盐引，指定盐商 | 国库收入~30% | 60%入国库，40%入盐商 |
| **劫灰铁** | 设铁监，朝廷直营+授权代工 | 国库收入~15% | 80%入国库，20%入工匠 |
| **灵砂** | 理论上须通过监察司备案交易 | 无法统计 | 90%+归门派 |

### 4.2 盐引制度

"盐引"是朝廷发放的食盐经销许可证——持有盐引才能合法售盐。

```
朝廷 ──→ 发放盐引 ──→ 大盐商（东海沈氏等）
  ↑                        │
  │                        ↓
  └── 盐引收入（巨额）  ←── 盐商缴纳盐引费+按量纳税
                              │
                              ↓
                        分销至各地盐铺
                              │
                              ↓
                        百姓购买食盐（价格高于成本数倍）
```

**盐引的政治功能**：
- 盐是刚需——控制盐价=控制民生稳定的阀门
- 盐引份额的分配是朝廷**拉拢/惩罚商人**的工具
- 走私盐的暴利催生了庞大的地下经济——与魔道组织、游牧走私客交织

## 五、门派经济——朝廷管不到的"第二经济体"

### 5.1 门派的收入来源

| 来源 | 描述 | 合法性 |
|------|------|--------|
| **灵砂开采** | 洞天福地内的矿脉产出 | 合法（门派自有领地） |
| **弟子束脩** | 入门弟子缴纳的学费+供奉 | 合法 |
| **任务/赏金** | 接受委托完成任务的报酬 | 半合法（部分任务灰色） |
| **田产/商铺** | 门派名下的俗世产业 | 合法 |
| **门派岁贡反馈** | 朝廷岁贡中"以灵换粮"的交易 | 合法 |
| **黑市灵砂** | 通过暗渠道出售灵砂 | 非法但普遍存在 |
| **保护费** | 向辖区内的商旅收取路费 | 半合法——取决于措辞 |

### 5.2 门派经济的规模

超品门派的年收入估计与一个中等府的税收相当——它们是**事实上的独立经济体**，拥有自己的"货币"（灵砂和灵石可以在武林内部充当一般等价物）。

## 六、当世经济危机——三根导火索

| 危机 | 描述 | 影响 |
|------|------|------|
| **息渊土矿脉衰退** | 灵谷种减产已是公开秘密 | 粮价上涨→民间不安→饥民起义前兆 |
| **盐商势力膨胀** | 东海沈氏实力已超过多数二品门派 | 经济权力正在转化为政治野心 |
| **灵砂争夺白热化** | 洞天福地灵气紊乱导致灵砂产量不稳 | 门派间摩擦加剧→可能引发武林大战 |

> **系统视角**：三根导火索中至少有两根（息渊土衰退+灵气紊乱）是三百年周期律触发的前兆——**暴风即将来临**。
