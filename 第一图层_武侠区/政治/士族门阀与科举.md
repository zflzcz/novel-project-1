## 一、士族的起源与演化

### 1.1 从部族首领到世家大族

士族并非天然存在——他们是4500年历史长河中逐步固化的产物。

| 时期 | 精英阶层形态 | 驱动力 |
|------|------------|--------|
| **开天纪** | 部族首领/萨满 | 武力+灵气感应天赋 |
| **仙人纪** | 受仙人教化的家族 | 被初代人类选中传授知识 |
| **封锁纪** | 掌握文字的祭司家族 | 仙宫焚毁后，文字成为最稀缺的知识 |
| **诸国纪初** | 军事贵族/功勋世家 | 开国功臣以军功获封土地 |
| **诸国纪中后** | 文化-经济-官僚复合体 | 科举制+土地兼并+商业扩张融为一体 |
| **当世** | "四位一体"精英阶层 | 官僚+地主+商人+武者资助人 |

### 1.2 "四位一体"的运作机制

一个典型的大族并非只做一件事——它同时运营四条权力线路：

```
        ┌──────────────────────────────────────────────┐
        │              士族大家族（核心：家主）           │
        └──┬──────────┬──────────┬──────────┬──────────┘
           │          │          │          │
     ┌─────┴────┐ ┌───┴────┐ ┌──┴───┐ ┌───┴─────┐
     │ 官僚支脉 │ │ 地产支 │ │ 商贸 │ │武学资助  │
     │          │ │ 脉     │ │ 支脉 │ │ 支脉    │
     │ 长子入仕 │ │ 管理庄 │ │ 经营 │ │ 资助弟  │
     │ 占据要职 │ │ 园田产 │ │ 盐铁 │ │ 子入门  │
     │          │ │        │ │ 茶马 │ │ 派修行  │
     └──────────┘ └────────┘ └──────┘ └─────────┘
          ↓             ↓          ↓          ↓
     政治保护 ←→ 经济根基 ←→ 资本积累 ←→ 武力庇护
```

**自我强化的闭环**（参照《中国官僚政治研究》）：

1. **官僚→地产**：做官可以"合法化"土地兼并——利用行政权力低价购入民间土地，或在灾年以赈济为名收购破产农户的田产
2. **地产→商贸**：土地产出的粮食和原材料进入家族控制的商贸网络，高价出售获取暴利
3. **商贸→武学资助**：商业利润的一部分用于资助族中子弟拜入武学门派——以换取门派对家族的武力保护
4. **武学资助→官僚**：家族中出身门派的武者弟子可以通过武者监察司系统入仕——或者以武力为后盾在地方上"保驾护航"，确保家族的政治地位不被动摇

> **底层逻辑**：这套闭环使士族成为了第一图层最稳定的持续性势力——"铁打的世家，流水的皇帝"并非虚言。朝代更迭时，士族们只需要在新旧势力之间及时"站队"，就能保全家业。

### 1.3 士族的等级划分

| 等级 | 标准 | 特权 | 数量（景朝约） |
|------|------|------|--------------|
| **一等门阀** | 连续三朝以上出任宰辅/尚书 | 恩荫入仕（不经科举）、皇室联姻资格 | 5-8家 |
| **二等世家** | 连续两朝以上出任知府以上 | 有限恩荫、经济特权 | 20-30家 |
| **三等名门** | 有科举进士传承 | 地方名望、教育资源 | 100+家 |
| **寒门** | 有读书传统但无世代做官 | 理论上的科举平等权 | 数千家 |
| **平民** | 无读书传统 | 几乎无上升通道 | 绝大多数 |

## 二、科举制度——"公平"外衣下的阶级固化

### 2.1 制度沿革

| 朝代 | 选官方式 | 特征 |
|------|---------|------|
| **太初朝** | 仙人荐举 | 无制度，仙人直接点名 |
| **承天朝** | 察举制 | 由地方长官推荐"贤能" |
| **明河朝** | 九品中正制 | 品评门第，"上品无寒门" |
| **永安朝** | **科举制创立** | 永安首辅制定考试选拔体系 |
| **景朝** | 科举制完善 | 四级考试+恩荫/捐纳并行 |

### 2.2 景朝科举的四级体系

```
                    ┌───────────────┐
                    │   殿试        │ ← 皇宫，皇帝亲试
                    │ 状元/榜眼/探花│    直入翰林院
                    │ 一甲三名      │
                    └───────┬───────┘
                    ┌───────┴───────┐
                    │   会试        │ ← 天京贡院
                    │ "进士"资格    │    通过率~5%
                    │ 约200-300人/科│    可任六品以上
                    └───────┬───────┘
                    ┌───────┴───────┐
                    │   乡试        │ ← 各道首府
                    │ "举人"资格    │    通过率~10%
                    │ 每道约50-100人│    可任县级小官
                    └───────┬───────┘
                    ┌───────┴───────┐
                    │   童试        │ ← 县学
                    │ "秀才"资格    │    通过率~30%
                    │ 免徭役特权    │    社会地位提升
                    └───────────────┘
```

### 2.3 考试内容——思想控制的精密武器

**考试科目**：

| 科目 | 内容 | 隐性功能 |
|------|------|---------|
| **经义** | 解释"天道经典"（类似四书五经） | 锁定思维框架——不允许质疑"天道" |
| **策论** | 就国事提出政策建议 | 筛选"能为朝廷服务"的思维方式 |
| **诗赋** | 作诗填词 | 培养文化认同和审美品味 |
| **武论**（景朝独创） | 论述朝廷与武林关系 | 灌输"武者应服从朝廷管辖"的理念 |

**"八股"式限制**：
- 答题必须引用经典原文，不可提出"异端"见解
- 对"天道"的解释必须符合官方注疏
- 任何暗示"天道可知""天命可疑"的论述一律判不合格

> **参照《中国官僚政治研究》**：科举最大的功能不是选拔人才，而是**将天下读书人的智识全部引导到一条窄道上**——花费数十年研究如何解读"天道"经典，以至于没有精力去质疑"天道"本身是否存在。

### 2.4 科举的三大"暗门"

虽然科举宣称"有教无类"，但实际存在三条绕过科举的捷径：

| 暗门 | 机制 | 受益者 | 规模 |
|------|------|--------|------|
| **恩荫** | 三品以上官员可保举一子直接授官 | 一等门阀/二等世家子弟 | 每代约50-80人 |
| **捐纳** | 花钱买一个"候补"官衔 | 富商巨贾 | 每代约200-300人 |
| **门派推荐** | 超品门派可向监察司推荐人才入仕 | 门派弟子中的文武双全者 | 每代约10-20人 |

> 通过正式科举入仕的进士每科仅200-300人，而通过恩荫、捐纳、推荐入仕的"特权阶级"加起来与之相当——**"公平"只是给底层看的幻觉**。

### 2.5 落第者的命运——被系统利用的苦难

绝大多数读书人终其一生都无法通过科举。他们的命运：

| 命运 | 描述 | 系统视角 |
|------|------|---------|
| **私塾先生** | 在家乡教书度日，维持家族的文化传承 | 稳定产出低烈度的失落/怀才不遇之情 |
| **幕友/师爷** | 寄人篱下为知县做参谋 | 产出屈辱/自我怀疑的情感数据 |
| **流民文人** | 四处游荡卖文为生 | 产出漂泊/孤独的高质量数据 |
| **黑暗转向** | 投身魔道/加入叛军/沦为邪教文书 | 产出绝望→疯狂的极端数据 |

> **叙事价值**：落第文人是第一图层最适合做"反面角色"或"悲剧角色"的群体之一——他们有才华、有野心、但被体制碾碎。如果主角的某个重要对手是一位落第文人转投魔道的角色，将极具戏剧张力。

## 三、士族与其他势力的博弈

### 3.1 士族 vs 皇权

| 盛世 | 衰世 |
|------|------|
| 皇帝需要士族治理国家 | 皇帝试图打压士族势力 |
| 士族通过科举为朝廷输送人才 | 皇帝扶持寒门或武者对抗士族 |
| 双方通过联姻维持平衡 | 士族暗中串联准备"换马" |

### 3.2 士族 vs 武林

| 合作模式 | 对抗模式 |
|---------|---------|
| 资助族中子弟入武学门派 | 门派弟子在士族地盘闹事 |
| 以经济资源换取武力保护 | 士族试图以行政手段限制门派扩张 |
| 士族与门派联姻（武者嫁入世家） | 利益冲突时暗中给对方下绊子 |

### 3.3 士族 vs 暗卫

暗卫对士族的监控最为严密——因为**士族是最有能力发动宫廷政变的群体**。

- 士族家族中常有暗卫细作潜伏（以家仆或管家身份）
- 士族同样会尝试收买暗卫中的低层成员
- 双方之间的情报战是"庙堂暗面"最精彩的博弈

## 四、当世士族格局（景朝·武安四十七年）

### 4.1 五大一等门阀

| 家族 | 根据地 | 核心优势 | 政治立场 |
|------|--------|---------|---------|
| **天京陆氏** | 天京 | 连续四代出任内阁首辅 | 维护现有秩序 |
| **蜀中景氏旁系** | 蜀中盆地 | 皇族远亲，掌控蜀中粮仓 | 皇室忠臣 |
| **东海沈氏** | 东海港城 | 掌控盐铁贸易八成份额 | 暗中资助某门派 |
| **中原王氏** | 天河中游 | 万亩良田+灵谷种最大私营产地 | 首鼠两端 |
| **北疆边境韩氏** | 长城要塞 | 世代镇守边关，兼有武学传承 | 军事色彩浓厚 |

> **注**：以上为框架设定，具体名称和关系可在大纲写作中进一步调整。

### 4.2 士族圈的暗流

- 天京陆氏与东海沈氏的联姻谈判已进行三年——若成功，将诞生一个"文通政坛、商控海贸"的超级门阀
- 中原王氏暗中与某超品门派接触，疑似在"第八次天灾"来临前谋求武力保障
- 北疆韩氏因边境紧张而大幅扩充私兵——朝廷对此睁一只眼闭一只眼，因为确实需要韩氏守边
