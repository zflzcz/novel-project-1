## 一、历史沿革

| 朝代 | 机构名 | 定位 | 权力等级 | 结局 |
|------|--------|------|---------|------|
| **承天朝** | 武者监察司（初创） | 六部下属末等衙门 | 仅能登记备案 | 随承天朝灭亡瓦解 |
| **明河朝** | 武者监察司（衰落） | 沦为收税工具 | 被商人和武者同时蔑视 | 被三大剑派摧毁 |
| **清虚朝** | （名存实亡） | 完全被门派架空 | 零 | 不存在 |
| **天元朝** | 武英殿（升格） | 独立机构，直属大汗 | 中等——由武者高手把持 | 随天元朝崩溃解体 |
| **大梁朝** | 武者监察总署+灭武令 | 试图全面控制武林 | 极高但难以执行 | **灾难性失败** |

## 二、景朝·组织架构

```
                    ┌──────────────┐
                    │    司正      │ ← 宗师境，朝廷任命，正三品武官
                    └──────┬───────┘
           ┌───────────────┼───────────────┐
     ┌─────┴─────┐  ┌─────┴─────┐  ┌─────┴─────┐
     │  登记处   │  │  仲裁处   │  │  缉拿处   │
     │（从四品）  │  │（从四品）  │  │（从四品）  │
     └───────────┘  └───────────┘  └───────────┘
```

### 2.1 登记处——武林的"户口本"

| 登记项目 | 内容 | 门派配合度 |
|---------|------|-----------|
| **门派登记** | 名称、所在地、掌门、弟子规模 | 一品以下完全配合。超品象征性报备 |
| **弟子名册** | 姓名、籍贯、境界 | 核心弟子信息往往被隐瞒 |
| **武学备案** | 功法名录（仅名称） | 禁忌功法不会申报 |
| **灵砂交易** | 采购、使用、交易须报备 | 黑市交易完全不受监管 |

### 2.2 仲裁处——武林的"法院"

| 管辖类型 | 仲裁方式 | 约束力 |
|---------|---------|--------|
| 跨门派产权纠纷 | 审查证据+实地调查 | 中等 |
| 弟子叛逃 | 判定"背叛师门"与否 | 低 |
| 江湖仇杀 | 调查因果，判定过错方 | 极低——以武论道更快 |
| **武林大会** | 每三年主持排名+仲裁 | 高——广泛认可 |

**武林大会流程**：

| 日程 | 内容 |
|------|------|
| 第一日 | 开幕式（皇帝御笔题词，司正主持） |
| 第二~七日 | 各品级门派弟子分组比武 |
| 第八~九日 | 超品门派精英赛 |
| 第十日 | 封号授勋（"天下第一剑""武道新锐"等） |

> **系统暗面**：武林大会实际是系统的**战斗数据集中采样**——数千名武者在短时间内密集释放灵气，产出大量战斗情感数据。

### 2.3 缉拿处——监察司的"拳头"

**直属武力——"鹰"系列**：

| 等级 | 境界 | 人数 | 职责 |
|------|------|------|------|
| **金鹰令** | 宗师境 | 3-5人 | 战略威慑 |
| **银鹰使** | 炼气巅峰 | 20-30人 | 重大任务 |
| **铁鹰卫** | 炼气中阶+ | 200-300人 | 日常巡查/缉拿 |
| **鹰眼** | 炼气初阶 | 500+ | 各地耳目 |

**"鹰犬"的社会撕裂**：
- **朝廷视角**：忠勇之士，为国效力的模范
- **门派视角**：背弃江湖道义的"鹰犬"走狗
- **他们自己**：两面夹击——被朝廷当工具，被江湖鄙视

## 三、根本矛盾——"团长管军长"

司正是宗师境——超品门派坐镇的是天象境。武力差距决定了监察司**无法对超品门派形成真正威慑**。

**景朝的应对——双轨制**：

```
武林门派 ──→ 武者监察司（明面）── 登记/仲裁/通缉
    │
    └────→ 暗卫·人组（暗面）── 安插细作/监控天象境/定点清除
```

**双轨弊端**：监察司和暗卫缺乏信息共享；门派发现暗卫细作会连带不信任监察司。

## 四、禁忌功法管制

### 《禁武目录》

| 类别 | 禁止原因 | 代表功法 |
|------|---------|---------|
| **噬魂类** | 吞噬他人灵魂 | "九幽噬魂功" |
| **血祭类** | 以活人为代价 | "血河大法" |
| **尸傀类** | 操控死者灵魂残片 | "万尸傀儡术" |
| **逆天类** | 试图调用系统底层权限 | "破天一式"（残缺） |

**管制困境**：无法杜绝地下流通；灰色地带难以判定；超品门派功法不敢审查。

> **叙事价值**：主角若获得灰色地带功法——监察司"应当"缉拿，暗卫可能另有打算——三方博弈。
