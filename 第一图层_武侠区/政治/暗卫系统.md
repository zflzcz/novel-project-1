## 一、创立背景

景太祖以蜀中世家子弟之身、仅凭宗师境下品修为夺取天下——他比任何人都明白**信息才是真正的权力**。

景太祖建国后，总结前朝覆灭根因：
- 承天朝：不知北疆动态→被铁狼部突袭
- 明河朝：不知门派野心→被三大剑派攻入天京
- 大梁朝：不知宗教渗透→天道教教主暗中颠覆
- 永安朝：三权制衡精妙但缺乏**预警系统**→等到天灾来时为时已晚

结论：**必须建立一套独立于六部、监察司之外的情报暗杀机构**——只对皇帝个人负责。

## 二、组织架构

```
                皇帝（唯一指挥者）
                 │
            暗卫统领（天象境或宗师巅峰）
                 │
         ┌───────┼───────┐
         │       │       │
       天组     地组     人组
      （对外）  （对内）  （对武林）
```

### 2.1 天组——对外情报

| 任务方向 | 具体职责 | 方法 |
|---------|---------|------|
| **北疆草原** | 监控游牧各部动向、兵力部署 | 商旅伪装、边境暗哨、收买部族内线 |
| **西境高原** | 监控隐世宗门、灵砂产出波动 | 伪装求道者潜入宗门外围 |
| **南荒** | 监控蛊师部落、深渊裂缝异动 | 暗哨+药贩网络 |
| **东海** | 监控海贸走私、海外势力 | 渗透商会、海港税关 |

### 2.2 地组——对内监控

| 任务方向 | 具体职责 | 方法 |
|---------|---------|------|
| **地方官员** | 监控官员贪腐、私通外敌 | 以家仆、管家身份潜伏于府衙 |
| **士族门阀** | 监控大族政治动向、联姻密谋 | 以师爷、账房身份渗透 |
| **民间舆情** | 监控谶纬、歌谣、宗教活动 | 茶馆、酒肆、集市的耳目网 |
| **朝廷百官** | 监控朝中派系斗争 | 宫内太监、侍卫中的暗线 |

### 2.3 人组——对武林（最核心、最危险）

| 任务方向 | 具体职责 | 方法 |
|---------|---------|------|
| **超品门派** | 监控天象境高手动向 | 在门派底层弟子/外门中发展线人 |
| **一二品门派** | 监控势力消长、联盟动态 | 暗卫成员以散修身份混入 |
| **魔道组织** | 追踪魔道据点、禁忌功法流通 | 双面间谍+赏金悬赏 |
| **散修高手** | 招揽或监控流浪高手 | 以"朝廷密旨"名义拉拢 |

## 三、暗卫的招募与训练

### 3.1 人才来源

| 来源 | 比例 | 特点 |
|------|------|------|
| **孤儿收养** | ~40% | 从小培养绝对忠诚——但可能缺乏社会经验 |
| **罪犯赎身** | ~20% | 以"立功赎罪"换取暗卫身份——忠诚度存疑 |
| **门派叛逃者** | ~15% | 自带武学基础和门派情报——但可能是反间 |
| **科举落第者** | ~15% | 有文化有野心，但被体制抛弃——愤怒可用 |
| **世家庶子** | ~10% | 了解门阀运作但无继承权——借暗卫翻身 |

### 3.2 训练体系

| 阶段 | 时长 | 内容 |
|------|------|------|
| **初训** | 3年 | 基础武学+情报技术（密码、跟踪、伪装、毒药） |
| **专训** | 2年 | 分入天/地/人组，针对性训练 |
| **实习** | 1年 | 在真实任务中作为辅助人员 |
| **正式** | — | 独立执行任务 |

### 3.3 暗号与通信

- **蜡丸密信**：情报写在蜡丸内，由信鸽或人力传递
- **暗语体系**：以商贸用语为掩护——"三十匹白绢到货"="某门派调动了三十名弟子"
- **死信点**：分布在各大城市的固定情报交接点（茶楼、药铺、当铺后门）
- **紧急烽火**：边境暗哨的物理信号系统——点燃特殊灵草，烟色不同代表不同等级的警报

## 四、暗卫的权力边界与失控风险

### 4.1 理论上的边界

景太祖立下的"**暗卫三戒**"：

| 戒律 | 内容 | 遵守情况 |
|------|------|---------|
| **不得干政** | 暗卫只负责情报和暗杀，不得参与日常行政 | 景朝前期严格遵守，后期越来越模糊 |
| **不得私杀** | 暗杀必须有皇帝密旨 | 中期起暗卫统领开始"先斩后奏" |
| **不得结党** | 暗卫成员之间不得私结关系 | 完全被违反——暗卫内部派系丛生 |

### 4.2 当世的失控迹象

| 迹象 | 描述 |
|------|------|
| **权力膨胀** | 暗卫统领的实际权力已超过武者监察司司正和部分六部尚书 |
| **信息垄断** | 皇帝几乎只通过暗卫获取外界信息——形成严重的**信息茧房** |
| **内部腐化** | 部分暗卫利用身份便利敲诈门派、收取保护费 |
| **反渗透** | 某些超品门派已成功在暗卫中发展了自己的线人 |
| **暗杀滥用** | "定点清除"的标准越来越低——从"威胁皇权"扩大到"可能威胁" |

### 4.3 历史教训

> **马基雅维利的告诫**：君主必须善用"狐狸"（诡计/情报），但如果整个治理体系都建立在"狐狸"之上而缺乏"狮子"（公开的武力和正义），最终狐狸们会反噬主人——因为他们比任何人都更了解主人的弱点。

> **中国官僚政治映射**：暗卫系统类似于历史上的宦官/锦衣卫——皇帝为了制衡外朝官僚而培养的"内廷势力"。这些势力初始忠诚于皇帝个人，但一旦形成自己的利益集团，就会从工具变成主人。

## 五、暗卫与其他势力的关系矩阵

| 势力 | 暗卫的态度 | 对方的态度 |
|------|-----------|-----------|
| **皇帝** | 绝对效忠（理论上） | 依赖但不敢完全信任 |
| **内阁** | 暗中监控 | 忌惮但表面尊重 |
| **监察司** | 利用但不共享信息 | 被蒙在鼓里，偶尔冲突 |
| **超品门派** | 最优先监控目标 | 知道暗卫存在但难以根除 |
| **士族门阀** | 渗透窃取情报 | 尝试收买暗卫低层成员 |
| **魔道** | 不惜一切消灭 | 视暗卫为最大敌人之一 |
| **系统代理人** | 不知道代理人存在 | 可能借暗卫为工具——也可能视暗卫为障碍 |

## 六、当世暗卫统领——最危险的人

当代暗卫统领是景朝第十一任统领。传闻其修为已达宗师境巅峰，半步天象——若属实，他将是**朝廷体系内距离天象境最近的人物**。

| 特征 | 描述 |
|------|------|
| **面容** | 据说终年以面具示人，朝野中见过其真容者不超过五人 |
| **忠诚** | 对皇帝表现出绝对忠诚——但"绝对忠诚"本身就令人不安 |
| **野心** | 不明——这才是最可怕的 |
| **与皇子关系** | 传闻与某位皇子关系匪浅 |

> **叙事价值**：暗卫统领是"庙堂线"中最具悬念的角色之一——他到底是皇帝最忠诚的刀，还是最危险的定时炸弹？他的真实身份是否与系统代理人有关？
