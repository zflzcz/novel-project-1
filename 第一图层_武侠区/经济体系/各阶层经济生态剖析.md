## 核心设定：全图层的财富金字塔

```text
                          ▲
                         /|\
                        / | \
                       /  |  \    【皇帝 + 内阁】
                      /   |   \    名义上掌握一切
                     /    |    \   实际：国库空虚/借外债续命
                    /─────┼─────\
                   /      |      \   【士族门阀 + 超品门派】
                  /       |       \   免税豪强/灵砂垄断者
                 /        |        \  占全图层财富的 ~45%
                /─────────┼─────────\
               /          |          \  【四大盐商 + 漕帮 + 镖局高层】
              /           |           \  商业寡头/物流垄断
             /            |            \ 占全图层财富的 ~20%
            /─────────────┼─────────────\
           /              |              \  【中低品武者 + 中小商人 + 城镇居民】
          /               |               \  "有技术的打工人"
         /                |                \ 占全图层财富的 ~15%
        /─────────────────┼─────────────────\
       /                  |                  \  【底层农民 + 佃户 + 矿工 + 流民】
      /                   |                   \  "燃料阶层"——承受一切剥削
     /                    |                    \ 占全图层人口的 ~75%，但仅占财富的 ~5%
    └─────────────────────┴─────────────────────┘
```

> *75%的人口，5%的财富。这不是偶然——这是系统的最优数据收割结构。足够的苦难产生足够的绝望，足够的绝望产生足够高烈度的情感数据。*

## 一、皇帝与朝廷——账面辉煌，内里空虚的纸老虎

### 1.1 朝廷财政总账（武安四十七年）

| 收入项 | 年收入（万两白银当量） | 备注 |
|--------|---------------------:|------|
| 田赋 | ~800 | 灵谷种减产，实际征收率仅计划的70% |
| 盐铁专卖 | ~600 | 内陆劣质盐引贬值，实际收入缩水 |
| 商税+关税 | ~300 | 沿海关税大部分已被东海"代管" |
| 门派岁贡（灵砂折银） | ~150 | 超品门派年年拖欠，实际到账不足100 |
| **合计收入** | **~1,850** | |

| 支出项 | 年支出（万两白银当量） | 备注 |
|--------|---------------------:|------|
| 禁军军饷 | ~500 | 六万禁军驻京师 |
| 边军九镇军饷 | ~800 | 十三万边军（大部分以盐引发放） |
| 官僚系统俸禄 | ~400 | 数万名官员+吏员 |
| **战争债券年息** | **~300** | **归墟联盟的利息账单** |
| 皇室开支 | ~100 | 宫廷运转 |
| **合计支出** | **~2,100** | |

**年度赤字：~250万两**

这个赤字怎么填？三种方式的恶性循环：
1. **继续借新债还旧债**（向归墟联盟发新一轮战争债券）
2. **超发大景宝钞**（隐形通胀税，从底层洗劫）
3. **超发盐引**（把贬值成本转嫁给边军）

### 1.2 朝廷的经济困境

```text
             收入在萎缩          支出在刚性增长
                ↓                     ↓
     ┌──── 灵谷减产 ────┐    ┌── 边防压力增大 ──┐
     │   内陆盐引贬值    │    │  官僚机构膨胀    │
     │   沿海税被代管    │    │  债务利息滚雪球  │
     └────────┬─────────┘    └────────┬─────────┘
              │                       │
              └──────────┬────────────┘
                         ↓
                  年度赤字 ~250万两
                         ↓
              ┌─── 怎么填？ ───┐
              ↓        ↓        ↓
         借新债    印宝钞    发盐引
          (毒药)   (毒药)    (毒药)
```

## 二、士族门阀——免税豪强的黄金时代

### 2.1 士族的经济特权

士族门阀是第一图层最大的既得利益群体。他们的经济地位建立在三大特权之上：

| 特权 | 内容 | 经济影响 |
|------|------|---------|
| **免税权** | 举人以上功名可免田赋 | 越来越多的农民"投献"田产给士族以避税 → 国家税基缩窄 |
| **土地兼并** | 不受限的土地买卖权 | 三百年来，全国60%的耕地已集中在不到5%的家族手中 |
| **离岸转移** | 通过赵氏钱庄将资产转移至东海 | 大量白银和灵砂外流 → 中原实际货币供应减少 |

### 2.2 士族的典型"账本"

以中原"五大世家"之一的**王氏家族**为例：

| 收入项 | 年收入（万两） | 来源 |
|--------|------------:|------|
| 庄园地租 | ~30 | 6万亩田产，佃户缴纳50%收成 |
| 商铺经营 | ~15 | 帝都三十余间店铺 |
| 官场灰色收入 | ~20 | 族中十余名在朝官员的"冰敬碳敬" |
| 海外投资回报 | ~10 | 东海离岸账户的"理财收益" |
| **合计** | **~75** | |

| 支出项 | 年支出（万两） | 说明 |
|--------|------------:|------|
| 田赋（理论应缴） | ~15 | **实际缴纳不足5万**——利用免税权避税 |
| 行贿/疏通 | ~10 | 维持政治关系 |
| 家族奢靡 | ~20 | 宅邸修缮/宴饮/收藏 |
| 族中子弟修行 | ~15 | 购买灵砂/聘请客卿教习 |
| **合计** | **~50** | |

**年净盈余：~25万两**——其中大部分被转移至东海离岸账户。

> *士族不怕改朝换代——因为他们的钱不在国内。他们怕的是东海被打掉，或者新皇帝查抄离岸资产。*

## 三、武林门派——不缺钱但缺粮的独立经济体

### 3.1 门派的"灵砂本位"经济

超品门派内部不使用朝廷的任何货币。灵砂就是他们的钱、他们的军火、他们的战略储备。

| 收入项 | 年收入（灵砂当量） | 说明 |
|--------|-----------------:|------|
| 洞天福地灵砂开采 | ~200两 | 核心收入——垄断性资源 |
| 弟子束脩 | ~30两 | 入门费+年费 |
| 任务报酬 | ~20两 | 接受外部委托 |
| 田产商铺 | ~50两（折算） | 门派名下的俗世产业 |
| **合计** | **~300两灵砂** | 约等于30万两白银 |

| 支出项 | 年支出 | 说明 |
|--------|------:|------|
| 弟子修行消耗 | ~100两灵砂 | 突破瓶颈、炼器等 |
| 朝廷岁贡 | ~30两灵砂 | 名义上"进贡"，换取朝廷不干预 |
| 外购粮食/铁器 | ~80两灵砂（折算） | **门派最大痛点——无法自产** |
| 门派运转 | ~40两灵砂 | 阵法维护/建筑修缮 |
| **合计** | **~250两灵砂** | |

**年净盈余：~50两灵砂**——看似富裕，但门派的致命弱点是**粮食和军工材料完全依赖外部输入**。

一旦朝廷切断粮食供给（或漕帮提高运价），门派弟子再强也得饿肚子。这就是为什么超品门派虽然"瞧不起"朝廷，却从不敢真的翻脸。

## 四、边军九镇——盐引经济下的牺牲品

### 4.1 大同镇的"军饷账本"

以大同镇（第一镇，总兵穆铁衣，兵力约3万）为例：

| 军饷项 | 账面金额 | 实际到手 | 差额原因 |
|--------|--------:|--------:|---------|
| 月饷（正银） | 3两/人 | 1两/人 | 70%以盐引发放，盐引贬值至面值30% |
| 季度冬衣银 | 2两/人 | 0.5两/人 | 兵部层层截留 |
| 年度赏银 | 5两/人 | 0两/人 | "国库困难暂缓" |
| 战功赏银 | 视战功 | "记账不发" | "待国库充裕后补发"（永远不会补） |

**士兵实际年收入**：约15-18两白银（含盐引折算）。
**维持一家温饱的最低线**：约20两白银/年。

**差额 = 饥饿。**

### 4.2 边军的生存策略

面对系统性的欠饷，大同镇士兵发展出了自己的"影子经济"：

| 生存策略 | 描述 | 风险 |
|---------|------|------|
| **屯田** | 在防线后方开垦荒地自种粮食 | 分散了防守兵力 |
| **走私** | 与北疆游牧暗中交易（以铁器换马、换皮货） | 按律当斩 |
| **倒卖盐引** | 把盐引卖给盐商换现银（以30%面值） | 越卖越穷 |
| **收保护费** | 向过境商旅收"边防维护费" | 激化军民矛盾 |
| **吃空饷** | 军官虚报人头，多领军饷自肥 | 削弱实际战力 |

> *穆铁衣面临的不是"要不要打仗"的问题——而是"还能不能喂饱士兵撑到明天"的问题。*

## 五、四大盐商——最富也最危险的白手套

### 5.1 盐商的利润模型

四大盐商（沈、陆、方、赵）是第一图层表面上最富有的群体。但他们的财富是"借来的"——他们本质上是归墟联盟在中原的**代理经营者**。

| 收入项 | 年收入（万两） | 来源 |
|--------|------------:|------|
| 合法盐业利润 | ~200 | 内陆盐矿开采+盐引兑付差价 |
| 东海走私海盐利润 | ~500 | 以低价从归墟进高品盐，以高价卖入中原 |
| 战争债券包销佣金 | ~120 | 代归墟联盟向景朝发行债券，收5%佣金 |
| 洗钱/离岸服务费 | ~80 | 帮助门阀大族转移资产 |
| **合计** | **~900** | |

| 上缴项 | 年支出（万两） | 去向 |
|--------|------------:|------|
| 上缴归墟联盟分成 | ~400 | 必须上缴，否则全家灭门 |
| 行贿朝廷 | ~100 | 维持"合法"外衣 |
| 养私兵/暗桩 | ~50 | 保全自身安全 |
| 家族开销 | ~100 | 极尽奢华——但这也是"做戏"的一部分 |
| **合计** | **~650** | |

**年净盈余：~250万两**——看似巨多，但一旦归墟联盟翻脸或朝廷抄家，这些钱一夜之间就会蒸发。

盐商是**双面人**——在朝廷面前装忠臣，在归墟面前装仆人。谁倒他们都死。

## 六、底层农民——帝国的燃料

### 6.1 佃户的"生存账本"

以中原天河中下游的普通佃户家庭（五口之家）为例：

| 收入项 | 年收入 | 说明 |
|--------|------:|------|
| 佃种10亩田产出 | 20石灵谷 | 混有息渊土的肥田，亩产约2石 |
| 折银价值 | ~20两 | 按每石1两计 |

| 支出项 | 年支出 | 说明 |
|--------|------:|------|
| 地租（交给地主） | 10石（50%） | 标准佃租 |
| 正税（田赋+丁税） | ~2两 | 按制度应缴 |
| 附加税+陋规 | ~3两 | 地方官加派 |
| 差役折银 | ~1两 | 免役钱 |
| 口粮（全家5口） | 7石 | 勉强糊口 |
| 种子/农具 | ~1两 | 最低维持 |
| **合计支出** | **~17两 + 17石** | |

**净盈余计算**：
- 收入：20石谷 = 大约20两银
- 支出：地租10石 + 口粮7石 + 现银支出7两
- 剩余：3石谷 + 大约13两银？

**不对——这是理想情况。** 实际上：

1. **通胀侵蚀**：大景宝钞贬值，实际购买力只有账面的60%。
2. **灾年减产**：灵谷种近年减产20-30%，收成可能只有14-16石。
3. **临时摊派**：战争/修河/修路的额外劳役，一年可达30-50个工日。

**真实净盈余：接近零。** 一场小旱灾、一次额外摊派，就能把整个家庭推入"卖子卖女"的绝境。

### 6.2 从佃户到流民的三步转化

```text
步骤1：灾年或加派 → 交不起地租
    ↓
步骤2：地主驱逐 → 丧失耕种权 → 成为"无地游民"
    ↓
步骤3：流入城镇乞讨或加入天道教 → 成为"预备暴民"
    ↓
(如果三百年周期律触发大规模天灾)
    ↓
步骤4：流民→义军→改朝换代的炮灰
```

## 七、阶层经济生态总览

| 阶层 | 人口占比 | 财富占比 | 经济核心逻辑 | 主角可利用的杠杆 |
|------|--------:|--------:|-----------:|----------------|
| 皇帝/朝廷 | <0.1% | ~15% | 借债续命的纸老虎 | 揭露债务真相、制造财政恐慌 |
| 士族门阀 | ~3% | ~45% | 免税兼并+离岸转移 | 切断东海洗钱通道、逼其选边站 |
| 武林门派 | ~2% | ~10% | 灵砂垄断但依赖粮食 | 控制粮食供给、操控灵砂价格 |
| 盐商/漕帮 | ~1% | ~20% | 物流垄断+金融代理 | 揭露白手套身份、瓦解信任链 |
| 边军 | ~2% | ~3% | 盐引经济的牺牲品 | 揭示朝廷克扣真相、争取军心 |
| 中层市民 | ~17% | ~5% | 依附权力生存 | 通胀中最先觉醒的群体 |
| 底层农民 | ~75% | ~2% | 帝国的"燃料" | 星星之火，可以燎原 |

> *"因为就算你拥有堡垒，但如果你结仇于人民，任何堡垒都挽救不了你。" ——《君主论》*
