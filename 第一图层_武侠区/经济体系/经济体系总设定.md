## 一、经济体系总论——"三层六面"经济引擎

第一图层的经济不是一个静态的税收报表——它是一台永不停歇的**苦难发动机**。表面上，景朝治世太平，商贾繁荣；但剖到骨子里，这个经济体系的每一层运转都在吸取底层的血液，向上喂养权贵，向外被法外势力寄生。

## 二、四大基石资源——系统的"不可能三角"升级为"不可能四面体"

系统（零主）在第一图层放置了**四种不可或缺且地理分散的战略资源**，确保没有任何一方能够同时掌控全部四者而称霸：

```text
                   ┌──── 息渊土（粮食基石）────┐
                   │       控制者：景朝朝廷      │
                   │       产地：中原天河冲积平原  │
                   └────────────┬───────────────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
  ┌─────┴──────┐         ┌──────┴──────┐         ┌──────┴──────┐
  │ 劫灰铁/炎髓 │         │ 先天灵砂     │         │ 海凝盐晶    │
  │（军工基石）  │         │（武力基石）   │         │（经济特权）  │
  │ 控制：争夺中 │         │ 控制：超品门派│         │ 控制：归墟联盟│
  │ 产地：断裂带 │         │ 产地：洞天福地│         │ 产地：东海礁群│
  └────────────┘         └─────────────┘         └─────────────┘
```

**互卡逻辑**：
- **朝廷**有粮（息渊土）、有大军，但无绝顶高手也无优质海盐→必须向门派买武力、向东海买盐。
- **门派**有天象境高手（灵砂），但饿肚子且无精钢重铠→必须向朝廷换粮换铁。
- **东海**有钱有盐有系统Bug灵髓，但无产粮基地且无法深入陆权→必须寄生于中原消费市场+走私渠道。
- **边防**坐着劫灰铁矿脉，但被朝廷通过粮草和盐引牢牢掐住后勤→无法自立为王。

> *"这是一个每个人都有对方需要的东西，但谁也无法独吞的棋局——而棋手是系统本身。"*

## 三、帝国经济的生死循环——从盛世到崩溃的底层脚本

### 3.1 盛世阶段（0 ~ 150年）

新王朝初立，土地重新分配，人口从战乱低谷恢复。税基广阔，官僚机器尚未腐化。国库充盈，不需要借外债。

**系统视角**：这个阶段产出的情感数据（希望、奋斗、建设）是中等品质的"正面数据"，系统不急。

### 3.2 固化阶段（150 ~ 250年）

士族兼并土地，税基缩窄（越富的人越有办法避税，税负全部压到底层）。官僚体系自我膨胀（帕金森定律），行政效率下降但行政成本暴涨。军费因边防压力持续增长。

**关键转折**：当国库入不敷出时，皇帝面临两个选择——
- **A. 对内加税**：需要向纳税大户（门阀、门派）让渡政治权力→皇权自我削弱→不愿意。
- **B. 对外借债**：来钱快、隐蔽性强、不需要政治妥协→**这就是归墟联盟的入场时机**。

### 3.3 寄生阶段（250 ~ 300年）

外债利息滚雪球。为了支付利息，朝廷被迫将核心税源（盐引权、关税、矿产收益）抵押给债权人。优质收入被东海抽走后，朝廷只能用恶性手段从底层搜刮：超发货币、加派苛捐、强征差役。

**通胀传导链**：
```text
战争债券利息到期
    → 优质税源被东海代管
        → 朝廷超发"大景宝钞"填补赤字
            → 铜钱/白银被囤积（格雷欣法则：劣币驱逐良币）
                → 物价飞涨
                    → 官僚实行"价格管制"
                        → 合法市场瘫痪，黑市配给制横行
                            → 底层赤贫化，流民暴增
                                → 天道教吸收绝望弃民
                                    → 暴动引爆
```

### 3.4 崩溃阶段（300年 ± 50年）

三百年周期律在此刻降下天灾（降水减少/地脉异动），与经济崩溃形成共振。旧秩序在血火中粉碎。

**系统视角**：崩溃阶段是情感数据的**收割巅峰**——绝望、背叛、牺牲、疯狂，这些高烈度负面情感是系统最需要的"燃料"。
