## 总论——系统设计的"不可能四面体"

系统（零主）在创建第一图层时，将维系文明的四种核心资源**故意分散放置**于不同地缘板块，并确保每种资源的产地都被不同势力控制。这不是巧合——这是一套精密的**互卡棋局**，目的是防止任何一方大一统，确保图层永远处于内耗状态，持续产出高质量情感数据。

```text
              息渊土（粮）──── 朝廷中原
             /                          \
            /                            \
   劫灰铁/炎髓（军工）              先天灵砂（武力）
    边防断裂带/游牧帝国               西境洞天福地
            \                            /
             \                          /
              海凝盐晶（经济）── 东海归墟
```

**不可能四面体**定则：
- 控制粮食的无法控制武力上限 → 朝廷有百万大军但打不过天象境高手
- 控制武力的无法自产粮食 → 门派饿肚子就得向朝廷低头
- 控制经济的无法深入陆权 → 东海有钱但没有一寸陆地国土
- 控制军工的被后勤卡死 → 边军坐着铁矿却吃不饱饭

### 1.2 关键数据

| 指标 | 数值 | 备注 |

| **全图层灵谷种年产量** | ~5亿石 | 养活约4亿人口（人均约1.25石/年） |

### 1.3 危机：矿脉衰退

息渊土矿脉的衰退不是突然的——它是系统有意为之的**缓慢绞杀**。系统每隔三百年微调一次地脉参数，使息渊土的灵性逐渐下降。当灵性低于临界值，灵谷种就无法发芽——这就是三百年周期律在经济层面的**物理触发器**。

当前状态：
- 天河西岸主矿脉品位下降至30年前的75%
- 蜀中副矿脉因地震影响部分坍塌，产能减半
- 内陆盐湖附近新发现的小型矿脉暂时缓解了危机，但储量有限

## 二、劫灰铁/炎髓——"重甲与杀人的基石"

### 2.1 产业链全图

```text
【开采】                【冶炼】              【锻造】             【消耗】

(地震活跃区)            高炉+灵火淬炼         → 精钢级兵器          → 攻城器械
                                              → 灵器级兵器          → 灵器/灵宝
    │                      │                    │                    │
    ↓                      ↓                    ↓                    ↓

```

### 2.2 关键数据

| 指标 | 数值 | 备注 |
|------|------|------|
| **年产劫灰铁** | ~800万斤 | 仅能满足全军70%的装备需求 |

| **铁监数量** | 9座（每镇1座） | 大同镇铁监规模最大 |
| **军工坊** | 帝都1座直属皇家军工坊+各镇小型代工坊 | |
| **年流入黑市量** | 估~50万斤（6%） | 边军/铁监吏员私下倒卖 |

### 2.3 博弈焦点：谁控制矿场？

劫灰铁的产地在**边防断裂带走廊**——恰好是朝廷与游牧帝国的交战前线。这造成了一个尴尬的战略困局：

- **边军**坐在矿脉上，理论上可以就地开采。但朝廷通过"铁监使"（文官）控制采矿权，边军只能当劳力。
- **游牧帝国**每次南下的首要目标之一就是劫掠铁矿。苍狼汗国的骑兵装备严重依赖从断裂带缴获的劫灰铁。
- **朝廷**最恐惧的场景：边军总兵控制了矿脉+冶炼能力+军队→变成独立军阀。因此朝廷坚持"以文驭武"——铁监使由文官担任，定期轮换，且矿石必须运至帝都皇家军工坊锻造后再分配。

> *铁矿在前线。前线打仗。矿工就是士兵。士兵吃不饱。矿产量在下降。敌人在等着抢矿。——这是一个完美的死局。*

## 三、先天灵砂——"只有门派搞得到的超凡燃料"

### 3.1 产业链全图

【开采】               【精炼】              【分配】             【消耗】

(灵气浓度最高区域)      需宗师境以上操控      黑市外流极少量        → 灵器/灵宝锻造
                                                                  → 阵法铭刻

 外人不得进入洞天        (各派各有秘法)         5%岁贡朝廷;          每年消耗量≈产量
                                               5%流入黑市            供需极度紧张

### 3.2 关键数据

| 指标 | 数值 | 备注 |
|------|------|------|
| **全图层年产灵砂** | ~1,500两 | 三大超品门派占80%产能 |
| **太清剑宗产量** | ~500两 | 最大生产者 |
| **朝廷岁贡总额** | ~100两灵砂 | 朝廷用于禁军精锐修行 |
| **黑市流通量** | ~80两 | 通过各种灰色渠道外流 |
| **价格** | 1两灵砂≈1,000两白银 | 有价无市 |

### 3.3 灵砂的战略意义

灵砂是武者世界的"核燃料"——没有灵砂，门派就无法培养天象境高手；没有天象境高手，门派就失去了对朝廷的武力威慑。

这意味着：
- **灵砂储量=门派军事潜力**。太清剑宗之所以稳居超品第一，不仅因为剑道精深——更因为他们坐拥最大的灵砂矿脉。
- **朝廷获得灵砂的唯一途径**是通过"门派岁贡"——但超品门派年年拖欠、打折交付。如果门派彻底断贡，朝廷禁军中的武者精锐将在一代人内衰退。
- **黑市灵砂**是连接武林与世俗的暗纽带——走私灵砂的利润率高达500%以上。

|---------|-------------|-------------|
| **品质** | 低——杂质多，苦涩 | 极高——纯净，带微弱灵性，武者服用可微量助益修行 |
| **产地** | 内陆盐湖（原有2处+新增1处小型矿脉） | 东海礁群浅滩，受潮汐灵气结晶 |
| **控制者** | 朝廷铁监+方氏承包 | 归墟评议会完全垄断 |
| **价格** | 约0.05两/斤 | 约0.5两/斤（内陆黑市价，是内陆盐的10倍） |
| **年产量** | ~3亿斤（勉强满足全民需求） | ~5,000万斤（仅能满足中原高端市场+朝廷采购） |
| **朝廷态度** | 专卖垄断 | 名义禁止，暗中少量采购 |

### 4.3 归墟灵髓——第四资源中的"核武器"

归墟灵髓不是自然资源——它是**系统渲染边界Bug泄漏的副产品**。东海深处的变异海兽体内凝结了绕过系统法则的异常能量结晶。

| 属性 | 描述 |
|------|------|
| **用途** | 短暂突破境界限制、灵器异化强化、秘法炼丹 |
| **副作用** | 精神异化（"数据中毒"：使用者逐渐失去人性，行为变得erratic） |
| **年产量** | 极不稳定——取决于深海变异海兽的猎杀成功率 |
| **价格** | 一品灵髓≈10两灵砂≈10,000两白银 |
| **流通方式** | 纯黑市——通过归墟灵髓碎片形式在中原暗中流通 |

归墟灵髓的存在打破了系统精心设计的"三大资源互锁"——它是能够**绕过系统法则**的外挂物质。这就是为什么系统代理人对东海态度暧昧：他们既需要东海作为"混沌区"产出数据，又忌惮归墟灵髓可能被觉醒者利用来破解系统。

**关键洞察**：在这个四方博弈中，**东海归墟联盟是唯一一个不会被武力直接威胁的玩家**——因为它在海上，朝廷水师打不过去，门派也不擅长水战。这使得东海成为这盘棋中最"安全"的角——而金融武器又是最隐蔽的武器。

> *"系统设计了三把锁互卡三方。但东海是第四把——它不是锁，而是从锁匠口袋里偷出来的万能钥匙。"*
