## 一、导火索 #1：息渊土矿脉衰退——粮食危机

### 1.1 当前状况

| 指标 | 武安三十年 | 武安四十年 | 武安四十七年（当前） | 变化趋势 |
|------|-----------|-----------|-------------------|---------|
| 灵谷年产量 | 6亿石 | 5.5亿石 | ~5亿石 | ↓持续下降 |
| 灵谷价格 | 0.6两/石 | 0.8两/石 | 1.5两/石 | ↑↑急速上涨 |
| 帝都粮仓储备 | 2年余量 | 1年余量 | ~4个月余量 | ↓↓危险 |
| 流民数量 | ~50万 | ~120万 | ~300万+ | ↑↑↑失控 |

### 1.2 危机传导

```text
息渊土品位下降
    → 灵谷种亩产下降 20-30%
        → 地主减租？不——地主维持50%佃租不变
            → 佃户交完租后所剩无几
                → 交不起税 → 被地方官强征
                    → 破产 → 卖地给地主 → 沦为流民
                        → 流民涌入城镇 → 治安恶化
                            → 天道教大肆吸收绝望弃民
                                → "天降苦难""受苦升天"的教义广泛传播
```

### 1.3 朝廷的应对——全部失败

| 对策 | 预期效果 | 实际结果 |
|------|---------|---------|
| 开放蜀中副矿脉扩产 | 增加粮食供给 | 蜀中矿脉品位更低，增产有限 |
| 从东海购买海粮 | 缓解燃眉之急 | 归墟联盟趁机**以粮食换取更多债务条款** |
| 减免田赋 | 减轻农民负担 | 地方官照收不减——减的是国库收入，不是农民负担 |
| 强制抑制粮价 | 稳定市场 | 商人拒卖→合法粮市瘫痪→黑市粮价更高 |

## 二、导火索 #2：盐引超发——边军饥变临界

### 2.1 当前状况

| 指标 | 盛世标准值 | 当前值 | 备注 |
|------|-----------|-------|------|
| 年发行盐引总量 | 500万引 | 1,800万引 | 超发3.6倍 |
| 盐引实际兑付率 | 100% | ~30% | 七成盐引成为"废纸" |
| 大同镇军饷实发率 | 100% | ~33% | 士兵实际收入仅账面的1/3 |
| 九镇兵变未遂事件（近5年） | 0 | 7起 | 均被镇压但频率在加速 |

### 2.2 大同镇的引爆点

大同镇总兵穆铁衣面临的困局：

```text
       朝廷命令                穆铁衣的现实
    ─────────────           ─────────────
    "坚守防线"              士兵吃不饱
    "服从调度"              军饷是废纸
    "不得与北疆交易"        私下走私换粮是生存唯一出路
    "忠于朝廷"              朝廷在用盐引慢性饿死他的兵
```

穆铁衣目前的选择：
1. **继续忍耐** → 士兵逃亡率加速，战力持续下降，北疆一旦南下必破
2. **公开上书抗议** → 被朝廷猜忌为"拥兵自重"，暗卫会来"清理"
3. **暗中与北疆交易** → 换取粮食维持军队，但如果被查出按律当诛
4. **直接造反** → 短期可控制断裂带铁矿自给，但长期无粮食补给仍是死路

> *这是四条路都走不通的绝境——而系统恰恰需要这种"无路可走"的绝望来收割最高质量的情感数据。*

## 三、导火索 #3：战争债券违约——归墟的金融核弹

### 3.1 违约倒计时

|---------|------|------|
| 武安45年春 | 景朝首次延迟支付战争债券利息（延迟3个月） | 【已发生】 |
| 武安46年冬 | 第二次延迟利息（延迟5个月），归墟联盟发出"最后通牒" | 【已发生】 |

### 3.2 归墟联盟的准备

归墟联盟并不担心景朝违约——事实上，**他们一直在等待这一天**。

| 准备措施 | 目的 |
|---------|------|

| 赵氏钱庄加速转移内陆门阀存款至东海 | 制造恐慌+资本外逃 |
| 方氏开始囤积食盐不再向内陆供货 | 制造盐荒以要挟景朝不敢动武 |

### 3.3 违约后的场景推演

```text
武安47年秋：景朝宣布无力偿还500万两本金
    ↓
归墟联盟援引合同条款，宣布启动"债转股"
    ↓
沈氏"审计使"进驻沿海六道的市舶司和盐场
    ↓
朝廷的沿海税收被东海正式接管（每年损失~400万两）
    ↓

    ↓
只能更疯狂地超发宝钞和盐引
    ↓
```

## 四、导火索 #4：大景宝钞信用崩溃——终极引爆

### 4.1 当前状况

| 指标 | 景朝初年 | 武安二十年 | 武安四十七年（当前） |
|------|---------|-----------|-------------------|
| 宝钞发行总量 | 500万两 | 2,000万两 | **1.2亿两** |
| 白银准备金 | 500万两（100%） | 800万两（40%） | **1,800万两（15%）** |
| 民间接受度 | "官方一两=白银一两" | "打九折尚可" | **"只收现银不收宝钞"** |
| 黑市汇率 | 无黑市 | 1宝钞:0.9白银 | **1宝钞:0.3白银** |

### 4.2 宝钞崩溃的连锁反应

```text
宝钞信用跌至零
    │
    ├──→ 官员俸禄贬值为原来的1/3 → 官僚系统瘫痪/贪腐加剧
    │
    ├──→ 军饷（宝钞部分）变为废纸 → 禁军军心动摇
    │
    ├──→ 商人拒收宝钞关店 → 合法市场消失 → 黑市全面取代正规商业
    │
    ├──→ 朝廷祭出"价格管制令" → 商人更不肯卖 → 物资进入"配给制"
    │       → 有特权的权贵仍能买到物资
    │       → 无特权的底层活活饿死
    │
    └──→ 武者开始拒收一切朝廷官方货币 → 灵砂黑市成为全图层唯一的"真实经济"
            → 万宝阁成为事实上的"央行"
            → 朝廷对经济的最后一点控制力土崩瓦解
```

## 六、系统视角——这一切都是数据收割的最优剧本

从系统（零主）的角度，当前的经济崩溃不是意外——**这是数据收割脚本的第三幕高潮**。

| 幕次 | 对应阶段 | 主要情感数据产出 | 品质 |
|------|---------|-------------|------|
| 第一幕 | 盛世（0-150年） | 希望、奋斗、建设 | 中等（正面） |
| 第二幕 | 固化（150-250年） | 焦虑、嫉妒、阴谋 | 较高（腐蚀性） |
| **第三幕** | **崩溃（250-300年）** | **绝望、背叛、牺牲、疯狂** | **极高（系统最需要的峰值数据）** |
| 尾声 | 新朝建立 | 劫后余生的微弱希望 | 中等（启动下一轮循环） |

景朝目前正处于**第三幕的开场**——经济崩溃是第一个倒下的多米诺骨牌。紧随其后的将是军事崩溃（北疆南下）、社会崩溃（天道教暴动）、最终是政治崩溃（皇权瓦解）。

**主角恰好在这个时代觉醒。** 他面对的不仅是刀剑和功法的对决——更是一场看不见硝烟的**金融战争、物流战争和信息战争**。而要掀翻棋盘，他首先需要**看懂这盘棋**。

> *"一切大规模人类合作的根基，在于某个虚构故事。当故事不再被相信，帝国就会在一夜之间化为齑粉。" ——《人类简史》*
>
> *大景宝钞上印着"景朝永昌"四个大字。当这四个字不再有人相信的那一天——就是景朝终结之时。*
