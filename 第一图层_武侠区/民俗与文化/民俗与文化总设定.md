# 第一图层·民俗与文化总设定

> 所属：第一图层（古典农耕 / 武侠区）
> 状态：V1.0 初稿

---

## 一、信仰体系

### 天道信仰（主流）

- 世人普遍相信"天道"是万物的主宰和裁判者
- "天道"降下恩泽（风调雨顺）也降下惩罚（天灾雷罚）
- 武道修行的终极目标是"参悟天道"
- **底层真相**："天道"是系统规则的统称，"参悟天道"本质是逼近系统权限的调用

### 仙人传说（民间信仰）

- 民间流传"上古有仙人降世"的传说——这是初代人类活动的模糊记忆
- "仙宫崩塌"的故事被演绎为各种版本的神话
- 部分山野村落仍然祭祀"古仙"的遗迹——实际上是传送塔残骸的地表痕迹

### 轮回与因果（宗教性信仰）

- 人死后灵魂轮回转世——这是系统的记忆清洗与灵魂数据重封装
- 善恶因果报应——系统对灵魂数据波动的正负反馈循环
- "修来世"的观念广泛存在，是底层民众面对苦难时的精神支柱

## 二、社会阶层

### 凡人社会

| 阶层                | 描述                       |
| ------------------- | -------------------------- |
| **皇族/贵族** | 天命所归的统治者           |
| **士族/文人** | 掌握知识与政治资源         |
| **农民**      | 社会基石，占人口绝大多数   |
| **工匠/商人** | 社会地位"士农工商"排序偏低 |
| **平民**      | 最底层，世代不得翻身       |

### 武者阶层（独立于世俗）

- 武者拥有独立于世俗法律之外的"江湖身份"
- 入门修行即脱离凡人社会，以门派为家
- 武者之间论实力不论出身——"拳头即道理"
- 但高级门派的入门门槛往往与世俗背景有关（世家子弟优先）

### 阶层流动

- **唯一的阶层跳板**：武道修行。一个农家子弟若有武学天赋，可通过拜入门派实现阶层跃迁
- **底层真相**：这种"翻身"的可能性被系统精心维持在一个极低但不为零的概率上——这确保了底层民众永远保有"希望"，从而不会彻底麻木（麻木 = 灵魂数据萎缩 = 脑死亡）

## 三、语言与文字

- 通用语言：一种类似古代汉语的语言系统
- 文字体系：方块字（表意文字），与世俗通用
- **古仙文**：传送塔和上古遗迹中残留的文字——无人能解读，学者称之为"天书"
  - 底层真相：这是系统底层代码的表象投影
  - 主角的伴生灵宝可能具有部分解读能力

## 五、婚丧嫁娶

### 婚姻

- 凡人社会：父母之命、媒妁之言
- 武者社会：门派之间的联姻是常见政治策略
- 跨阶层联姻极为罕见，但不是绝对禁止

### 丧葬

- 主流方式：土葬（入土为安，灵魂归于轮回）
- 武者特殊传统：高手死后可能"坐化"——盘膝而逝，肉身不腐
  - 底层真相：高数据密度的灵魂在断连时，残余能量场暂时维持了物理载体的稳定
- 禁忌：焚尸——民间认为会烧毁灵魂，阻断轮回

## 六、饮食与日常生活

- 以农耕为基础，五谷杂粮为主
- 修行者注重"辟谷"——高境界武者可以不食五谷，以灵气代餐
  - 底层真相：灵魂数据密度足够高时，可直接从环境能量池汲取维持载体的能量
- 酒文化盛行——"大碗喝酒、大块吃肉"是江湖标配
- 茶道在文人和高阶武者中流行——"品茗论道"

## 七、禁忌与忌讳

| 禁忌                       | 凡人理解           | 底层真相                             |
| -------------------------- | ------------------ | ------------------------------------ |
| **不可窥探天道**     | 天道不可冒犯       | 系统对异常数据访问的惩罚机制         |
| **不可亵渎古仙遗迹** | 仙怒降临           | 传送塔残骸的防护机制可能被触发       |
| **不可修炼禁忌功法** | 走火入魔，遗害无穷 | 非法提权操作可能导致灵魂数据永久损毁 |
| **不可轻言飞升**     | 天妒英才           | 系统监控对高算力灵魂的预警机制       |

> **文化的本质**：第一图层数千年积淀的文化，不过是无数灵魂在不知不觉中，对系统规则的集体性文化编码。他们用神话解释算法，用信仰包装铁律，用传说记忆被抹去的真相。
