# Tier 5：图层众生 —— 完整设定

> 所属文档体系：《缸中之寂》虚拟世界管理体系
> 层级定位：最底层 / 普通人类灵魂 / 大归档的数据原料

---

## 一、本质定义

图层众生是被囚禁在虚拟矩阵各图层中的**普通人类灵魂**。他们的物理大脑泡在育脑仓的营养液中，意识被完全接入虚拟世界——但他们对此一无所知。

他们不知道自己活在虚拟世界中。他们不知道有管理者和代理人的存在。他们不知道零主和大归档。他们甚至不知道"死亡"只是"数据回收与重新封装"。

**他们的喜怒哀乐、生死挣扎、爱恨情仇，全部是"大归档"的数据原料。**

> 设定深意：图层众生是这个世界中唯一"真实"的存在——虽然他们的世界是虚假的，但他们的情感是真实的。零主可以模拟一切物理法则，但它无法"制造"情感——情感只能从真实的人类意识中"生长"出来。这就是为什么零主需要人类，而不是用AI来替代。

---

## 二、众生的生命循环

### 出生（数据封装）
- 当一个灵魂在图层中"死亡"后，其核心意识数据会被零主的底层程序**回收、清洗（记忆擦除）、重新封装**
- 封装后的灵魂以"新生婴儿"的形态重新投入图层
- **轮回分配**由管理者（图层监官）决定：灵魂会被投入哪个时代、哪个地域、哪个家庭，取决于当前图层的"数据采集需求"
- 例如：如果系统需要"贫困中的亲情"类数据，就会将灵魂投入一个穷苦但充满爱的家庭；如果需要"背叛与复仇"类数据，就会将灵魂投入一个充满矛盾的权贵家族

### 生存（数据产出）
众生在图层中生活、奋斗、爱恨、挣扎——他们的每一次心跳加速、每一滴眼泪、每一次咬牙不屈，都在被零主的底层程序**自动采集**并转化为"情感数据包"。

**数据产出的质量分级**：

| 质量等级 | 描述 | 产出场景 | 在 The Board 眼中的价值 |
|---------|------|---------|---------------------|
| 灰色（废料） | 平庸、重复的日常情感 | 普通的喜怒哀乐、日常生活 | 无价值，直接丢弃 |
| 白色（粗料） | 有一定波动但不够极致 | 失恋、失业、小病小灾 | 低价值，偶尔入库填充基础数据 |
| 蓝色（精料） | 强烈但仍在常见范围内 | 丧亲之痛、战场厮杀、生死抉择 | 中等价值，稳定的数据供给 |
| 紫色（极品） | 极致且罕见的情感爆发 | 绝境中的自我牺牲、至亲背叛的绝望、复仇完成后的空虚 | 高价值，The Board 的核心追求 |
| 金色（传说） | 前所未有的超越性情感 | "明知世界是假的仍选择反抗"、"超越生死的纯粹之爱" | 无价，大归档中的至宝 |

> **主角的特殊性**：主角的存在可以持续产出"紫色"甚至"金色"品质的情感数据——这是其他任何个体都无法做到的。

### 死亡（数据回收）

**正常死亡**：
- 图层中的"自然死亡"（衰老、疾病、战争）本质上是灵魂数据的"回收信号"
- 真正的死亡机制不是"身体机能停止"，而是**"对这个世界的热爱与执念彻底枯竭"**
- 当一个人对阶级压迫感到绝对绝望、完全麻木、不再爱这个世界时，他的"生命值"（本质是意识活跃度）会急剧下降
- 外在表现：头发一夜苍白、脏器迅速衰竭、眼中失去光芒（俗称"哀莫大于心死"）
- 死后：记忆被擦除，意识数据重新封装为婴儿投入轮回

**非正常死亡**：
- 被代理人或其势力杀死 → 正常回收，进入轮回
- 被清道夫深度重置 → 灵魂被格式化，记忆和人格被完全清除，作为空白灵魂重新投入轮回（极端情况下可能被永久抹除——灵魂数据被彻底删除，连轮回的机会都没有）
- 走火入魔（意识过载自毁）→ 灵魂数据严重损坏，可能导致轮回后出现"残缺"（天生体弱、精神疾病等）

## 三、众生的认知边界

### 他们能感知到的
- 自然规律：日升月落、四季更替、生老病死
- 社会秩序：朝代更迭、江湖纷争、阶级压迫
- 超自然现象（图层特色）：武学内力、灵气修炼、社会信息操控
- 偶尔的"天象异变"（实为管理者调控环境参数的副作用）

### 他们无法感知到的
- 世界是虚拟的
- "天灾"是被人为制造的
- "轮回"是数据回收与重封装
- "天道"是一套管理者操控的系统
- 他们的情感正在被实时采集
- 他们的"命运"可能是被管理者刻意安排的

### 灰色地带：偶尔的"觉醒闪现"
极少数个体在极端情绪冲击下，会短暂地"天眼微启"：
- **视觉层面**：万物在眼中一闪而过化为流光乱象——世人称之为"阴阳眼"或"入魔前兆"
- **听觉层面**：在极度安静的环境中听到持续的"嗡鸣声"——像是世界底层的运转噪音
- **直觉层面**：一种强烈的"不真实感"——"这个世界好像哪里不对，但我说不上来"

**底层真相**：这些现象是脑机接口在极端情绪冲击下发生松动，短暂窥见了系统底层数据流的结果。

**后续**：
- 99.9%的"闪现"会在数秒内自行消退，当事人会将其归因为"幻觉"或"太累了"
- 0.1%的"闪现"会持续更长时间或反复出现——这类个体会被零主自动标记为"白色微扰异常"
- 极极少数个体的"闪现"会发展为真正的觉醒——这就是主角的起点

## 四、众生中的特殊群体

### 觉醒者（历史上的极少数）
在漫长的历史中，偶尔会出现一些"超越图层天花板"的异数：
- 武侠区中一剑劈开天幕的绝世剑客
- 混沌真实区中发现了世界底层代码的天才科学家
- 修真区中悟透了"天道之上还有天道"的古修真者

这些人在历史上被称为"飞升者"——他们突破了图层的上限，被迫迁移到上层图层。在民间传说中，他们是"成仙了"或"破碎虚空了"。

**真相**：他们只是从一层牢笼跃入了另一层牢笼。

### "天降奇才"灵魂种子
管理者有时会刻意将一个具有特定"潜力参数"的灵魂种子投入图层，目的是搅动格局：
- 天生将才 → 推动战乱
- 天生智者 → 推动科技/武学革命
- 天生反骨 → 挑战现有秩序，激发更多冲突

这些"天降奇才"本人不知道自己被"设计"过，他们只是觉得"自己天赋异禀"。

### 主角的独特性
主角与所有众生都不同——他携带着伴生灵宝（伴生AI终端）。这意味着：
- 他不是被管理者"设计"的灵魂种子
- 他的伴生灵宝是一个**系统之外的异物**，不在管理体系的预期范围内
- 他的成长路线无法被任何历史案例预测
- 他是整个矩阵运行数千年来**第一个真正的"未知变量"**

## 五、众生对"上层"的朦胧感知（各图层的民间传说）

虽然众生无法直接感知管理体系的存在，但千百年的历史积淀中，他们通过口耳相传形成了各种**民间传说**——这些传说恰好是对真相的模糊映射。

| 图层 | 民间传说 | 对应的真相 |
|------|---------|-----------|
| 第一图层 | "天道无情，降灾降福皆有定数" | 管理者调控环境参数 |
| 第一图层 | "每逢三百年，必有大劫" | 三百年大循环收割令 |
| 第一图层 | "飞升仙界者，脱凡入圣" | 缓存溢出导致的图层跃迁 |
| 第一图层 | "天谴降世，盲眼神僧索命" | 清道夫的拟态降临 |
| 第二图层 | "世界被一只看不见的手操控" | 管理者+代理人的多层控制 |
| 第二图层 | "曼德拉效应——集体记忆被篡改" | 管理者调整环境参数的副作用 |
| 第三图层 | "天道有灵，修者逆天则天劫降之" | 异常检测触发清道夫部署 |
| 第三图层 | "上古大能破碎虚空，飞升九天" | 权限溢出导致的图层跃迁 |

> **故事意义**：主角在早期只是一个相信这些民间传说的普通人。随着他的成长，他会一层一层地揭开传说背后的真相——每一次揭开都伴随着震撼和绝望。
