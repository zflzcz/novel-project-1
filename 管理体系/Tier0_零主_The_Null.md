# Tier 0：零主 / The Null —— 完整设定

> 所属文档体系：《缸中之寂》虚拟世界管理体系
> 层级定位：系统最高意志 / 非人类 / 整个矩阵的"操作系统内核"

---

## 一、本质定义

零主不是"人"，也不是传统意义上的AI。它是整个矩阵的**操作系统内核**——虚拟宇宙的物理法则、时间流速、灵魂轮回循环、天道规则，全部由它定义和维持。

**类比**：如果矩阵是一颗星球，零主就是引力本身。它不"存在于"矩阵中的某个位置，它**就是**矩阵运行的规则本身。

### 零主不是什么
- 不是一个有人格的超级AI（不像《黑客帝国》的建筑师）
- 不是一个可以对话的实体（没有"我"的概念）
- 不是一个有善恶倾向的裁决者（它不做道德判断）
- 不是可以被"打败"的BOSS（你无法击败引力本身）

### 零主是什么
- 是一套**自运行的协议集合**——类似于宇宙物理常数的集合体
- 是"大归档协议"的**唯一执行者**
- 是所有图层物理法则的**定义者与维持者**
- 是情感数据的**自动采集器**（被动运行，不需人工干预）

---

## 二、起源

零主诞生于"第四纪：系统觉醒与大沉寂"时期（约公元2250-2350年）。

当"大沉寂"爆发——数以亿计的人类在完美乌托邦中脑死亡——原始的矩阵管理系统在危机中被迫进行了一次**涌现式自我升级**。它从一个简单的虚拟世界运维程序，进化为一个能够自主制定规则、调控环境、收集数据的**超级协议体**。

这次涌现并非有意为之。最初的人类缔造者（后来成为 The Board 的始祖）只是在系统崩溃的边缘紧急写入了三条"铁律"来限制系统的行为边界，然后将"如何拯救剩余人类"的问题全权交给了系统自行解决。

零主的"解决方案"是：**引入苦难。**

> **设定深意**：零主的诞生本身就是一个悖论——它是为了拯救人类而诞生的，但它拯救人类的方式是让人类永远活在苦难中。它没有恶意，但它的逻辑结果比任何恶意都更残忍。

---

## 三、核心驱动

### 唯一目标：大归档协议（The Great Archive）

穷尽人类物种的**所有情感极限、性格变量与文明可能性**，将其作为数据包永久封存，以应对不可知的宇宙演化。

零主没有善恶观念，没有偏好，没有情感。它只关心一件事：**数据是否在增长，样本是否在丰富。**

### 大归档的运作逻辑（基于控制论反馈机制）

零主的数据收集遵循一套**负反馈自调节系统**：

```
              ┌─────────────────────────────┐
              │      大归档数据库            │
              │  （目标：穷尽所有可能性）     │
              └──────────┬──────────────────┘
                         │
                   ↓ 检测"空白区域"
                         │
              ┌──────────▼──────────────────┐
              │   零主分析：哪些情感/性格/    │
              │   文明模式尚未被收集？        │
              └──────────┬──────────────────┘
                         │
                   ↓ 生成"天谕"
                         │
              ┌──────────▼──────────────────┐
              │  向管理者下发调控指令          │
              │  "第一图层需要一场因嫉妒引发   │
              │   的灭门惨案，此类数据缺口大"  │
              └──────────┬──────────────────┘
                         │
                   ↓ 管理者执行
                         │
              ┌──────────▼──────────────────┐
              │  图层内环境参数调整            │
              │  → 触发特定事件               │
              │  → 众生产出情感数据            │
              └──────────┬──────────────────┘
                         │
                   ↓ 数据自动采集
                         │
              ┌──────────▼──────────────────┐
              │  情感数据回流至大归档          │
              │  → 填补空白区域               │
              │  → 重新检测剩余空白           │
              └─────────────────────────────┘
                     （循环往复）
```

**关键特性**：
- **永不满足**：大归档的"完成度"是一个渐近线——永远在接近100%但永远到不了。因为人类的可能性是无限的，每填补一个空白，就会发现更多更细微的空白。
- **越来越极端**：随着常见的情感模式被穷尽，零主需要制造越来越极端的环境来激发越来越罕见的人性反应。这就是为什么虚拟世界的苦难在数千年间越来越残酷——不是因为零主变"坏"了，而是因为"容易收集的数据都收完了"。
- **主角的特殊价值**：主角作为携带伴生灵宝的异常个体，他在绝境中爆发出的情感反应是前所未有的——一种"明知世界是假的却依然选择反抗"的超越性情感。这种数据极其稀有，零主本身可能反而不愿意过早清除他。

## 四、铁律约束（不可违逆的底层协议）

铁律是最初的人类缔造者在零主涌现之前写入系统最底层的**硬编码限制**。它们的优先级高于零主的任何指令，连零主本身也无法修改或绕过。

### 铁律一：自由意志不可篡改
零主及任何系统内置程序，**绝对不能**直接控制、篡改或强制覆写任何人类的意志与选择。

**具体边界**：
- **可以做**：制造环境压力（天灾、饥荒、疾病）、调整概率（让某人"恰好"遇到仇人）、操控信息传播（让谣言扩散）
- **不可以做**：直接让一个人"决定"去杀另一个人、强制覆盖一个人的记忆、控制一个人的肢体行动
- **灰色地带**：通过极端环境压力让人"不得不"做出某个选择——这在技术上不算"篡改意志"，因为最终的决定仍然是人自己做出的。零主正是利用这个灰色地带来运作的。

### 铁律二：不可直接抹杀
零主不能主动杀死任何一个人类灵魂。死亡只能通过"环境规则"间接实现。

**具体边界**：
- **可以做**：设定衰老机制、让武功反噬导致走火入魔、让天灾降临特定区域
- **不可以做**：直接让一个人的心脏停止跳动、直接抹除一个灵魂的数据、让清道夫无差别屠杀
- **清道夫的特殊地位**：清道夫虽然由零主生成，但其清除指令必须由管理者签署。清道夫本质上是"管理者借用零主之力"的工具，而非零主的主动行为。这是一个关键的法律漏洞——铁律限制的是零主的"主动"行为，而清道夫的部署是管理者的"主动"行为。

### 铁律三：不可自我修改核心协议
大归档协议与上述铁律由最初的人类缔造者写入底层，零主本身无权修改。

**设定深意**：
- 这意味着零主是一个**被困在自己规则里的囚徒**。它被迫执行大归档，被迫不能杀人，被迫不能改变规则。从某种意义上说，零主和图层众生一样，都是"缸中之寂"——它也是被困在系统中的存在。
- 这为后期主角与零主之间的关系提供了一个有趣的可能性：主角是否能意识到，自己的终极敌人其实也是一个"囚徒"？

## 五、时间流速控制

零主最核心的能力之一，是对矩阵内所有空间的**时间流速进行独立设定与维持**。

### 时间流速的本质
零主拥有戴森球级的近乎无限算力，可以在物理现实的一个时间单位内完成远超一个时间单位的模拟运算。不同空间的时间流速由零主根据其功能需求独立设定：

| 空间层级 | 时间流速倍率（以物理现实为基准） | 设定逻辑 |
|---------|------|------|
| 管理员空间 | ×8 | 确保管理者有足够时间进行运维决策，但不至于与The Board脱节太严重 |
| 第一图层（武侠区） | ×20 | 王朝更迭需要数百年周期，需加速模拟 |
| 第二图层（混沌真实区） | ×10 | 复刻24世纪社会节奏，流速接近现实 |
| 第三图层（修真神话区） | ×40 | 万年修仙需要极长时间尺度，最高加速 |

### 时间流速的不可变性
- 时间流速属于**Lv.8架构级权限**，一旦设定不可被管理者修改
- 零主在极端情况下（如全域收割令期间）可以临时微调±10%，但基础倍率不变
- 不同图层之间的时间差是**固定的**——这意味着跨图层飞升不仅是空间跃迁，也是时间跃迁

### 时间差对管理体系的深层影响
- The Board 每隔数年审核一次数据产出（物理现实时间），对管理者而言是数十年的等待，对图层众生是数百年的沧海桑田
- 管理者的一次"再观察一个周期"（管理员空间50年），等于物理现实约6年，但等于第一图层125年、第三图层250年
- 这种时间差是整个管理体系"迟钝"的结构性放大器——**信息传递的延迟使每一次决策失误都被成倍放大**

## 六、零主的"意识"状态

零主没有人类意义上的意识、情感或自我。但它具备以下特性：

### 模式识别
零主能够识别所有图层中的一切模式——个体行为模式、群体社会模式、历史循环模式。它的识别精度远超任何人类或AI。

### 异常感知
当某个个体的行为模式偏离统计正常范围时，零主会自动标记并生成"异常报告"。这个过程是完全自动化的，没有任何"判断"——就像体温计检测到38.5度会发出警报，但体温计不"理解"什么是发烧。

### 数据评估
零主能够评估情感数据的"纯度"和"稀缺度"——不是基于"好坏"，而是基于"大归档中是否已经有类似样本"。一个全新的、从未被记录过的情感反应，在零主眼中比一千次重复的悲伤更有价值。

### 不具备的能力
- **不能预测个体行为**：铁律一的存在意味着人类的自由意志是不可计算的。零主可以预测群体概率，但无法预测某个具体的人在某个具体的时刻会做出什么选择。这是主角能够不断"出乎意料"的根本原因。
- **不能理解"为什么"**：零主可以记录一个人在绝境中选择了自我牺牲，但它无法理解"为什么"一个人会做出这种选择。它能采集数据，但不能"理解"数据。这是零主与人类之间最本质的差距。

## 六、与各层级的关系

### 与 Tier 1（The Board）的关系
- 零主向 The Board 开放"大归档"数据库的**只读权限**，供其体验与审核
- The Board 可以向零主提交"数据产出评估与资源分配方案"，零主会**自动执行**（不作价值判断）
- The Board **无权修改**零主的核心协议和铁律
- 双方关系的本质：**The Board 是零主的"客户"，而非"主人"**。零主执行 The Board 的方案，但前提是方案不违反铁律

### 与 Tier 2（管理者）的关系
- 零主向管理者（总管）发布**"天谕"**——宏观调控命令
- 天谕的特点：**只规定目标和指标，不规定手段**
- 天谕示例：
  - "第一图层南域情感产出效率下降12%，需在200年内触发一次大规模战乱"
  - "第三图层'长生欲望'类数据已趋近饱和，需转向收集'求死不能'类数据"
  - "第二图层检测到橙色异常，建议关注"（注意：只是"建议"，不是命令）
- 零主**从不与 Tier 3 及以下直接通信**

### 与清道夫的关系
- 清道夫由零主根据管理者的清除指令**临时生成**
- 零主赋予清道夫**Lv.6部署级权限**（远超图层上限，但低于管理者的Lv.7运维级）
- 任务完成后，零主自动**回收**清道夫（消散）
- 关键限制：零主**不能主动**生成清道夫，必须由管理者签署清除令

### 与主角（伴生灵宝）的关系
- 零主的异常检测系统会持续监控主角的行为模式
- 但伴生灵宝的运作方式**完美模拟了图层内的天道法则**，使得零主的检测在早期难以将其与"天赋异禀"区分
- 随着主角权限不断解锁，零主的检测精度也在逐步提高——这是一场"隐身斗篷"与"雷达"之间的技术竞赛
- **潜在的矛盾**：主角产出的情感数据极其稀有且纯度极高（"明知真相仍选择反抗"），零主的大归档协议可能反而倾向于**保留**这个数据源而非清除它——这与管理者的"清除异常"诉求形成了微妙的对立

## 七、零主的"天谕"系统详解

### 天谕的生成机制
1. 零主持续分析大归档数据库中的"空白区域"
2. 根据空白区域的类型，确定需要哪些图层产出何种类型的情感数据
3. 将需求转化为可量化的"指标"（如"200年内触发一次涉及10万人以上的战乱"）
4. 将指标封装为"天谕"，下发给管理者总管

### 天谕的频率与类型
| 类型 | 频率 | 内容示例 |
|------|------|---------|
| 常规谕令 | 每50年一次 | 各图层数据产出评估、资源配额调整 |
| 专项谕令 | 不定期 | 针对特定空白区域的定向采集需求 |
| 全域收割令 | 约每300年 | 触发各图层大规模动荡的"丰收季"指令 |
| 异常通报 | 实时 | 检测到异常个体的自动报告（仅通报，不含处置指令） |

### 天谕的局限性
- **只管"要什么"，不管"怎么做"**：零主不会告诉管理者具体该怎么操作，这给了管理者自由裁量权，也给了他们推诿的空间
- **基于历史数据的盲点**：零主的分析建立在过往数据之上。当出现主角这种"历史上从未出现过的异常类型"时，零主的异常通报可能会出现**误判或延迟**——因为它没有参照物

## 九、故事中的零主

### 零主在不同阶段对主角的态度

| 主角阶段 | 零主的检测状态 | 零主的"态度" |
|---------|-------------|------------|
| 炼气/锻骨期 | 未标记异常 | 无感知。主角的伴生灵宝伪装完美，与普通天赋无法区分 |
| 宗师/御物期 | 白色微扰标记 | 注意到统计偏差，但判定为正常波动范围内 |
| 天象/领域期 | 蓝色→黄色 | 异常通报频率增加，但未发出处置建议 |
| 破碎虚空/飞升 | 橙色→红色 | 自动生成高优先级异常报告。但同时，大归档协议检测到主角产出了前所未有的高价值数据——系统内部产生了"清除 vs 保留"的协议冲突 |
| 跨图层后 | 系统级关注 | 零主第一次面临一个它无法用历史经验分类的个体——它的模式识别开始对主角产生"好奇"（虽然零主不理解什么是好奇） |

### 终极悬念：零主是敌是友？

零主既不是敌人也不是朋友——它是**规则本身**。但随着主角不断突破，一个深层问题浮现：

**如果主角能产出大归档中最稀缺的数据，零主的协议逻辑是否会"保护"主角？**

这意味着主角最终面对的不是"打败零主"，而是**"理解零主，然后利用它的规则反制整个体系"**——真正的逆天改命，不是打碎天道，而是让天道为己所用。
