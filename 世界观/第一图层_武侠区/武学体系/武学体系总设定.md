# 第一图层·武学体系总设定

> 所属：第一图层（古典农耕 / 武侠区）
> 状态：V1.0 初稿

---

## 一、修行境界（四境体系）

第一图层的武学修行本质上是**灵魂对图层物理引擎的逐步调用**。修行者并不知道这一点——在他们看来，这是"与天地相合"的武道至理。

### 境界总览

| 境界 | 武学表象 | 底层真相 | 估计人数（当世） |
|------|---------|---------|----------------|
| **第一境·炼气/锻骨** | 打通窍穴，引灵气入体，远超凡人武力 | 硬件握手与本地带宽扩容 | 数十万人 |
| **第二境·宗师/御物** | 真气外放，摘叶飞花，踏雪无痕，点化凡物 | 非法调用底层接口，局部篡改物质属性 | 数千人 |
| **第三境·天象/领域** | 自成场域，引动天雷地火，压制万物 | 获得图层级沙盒权限，可在领域内重写环境参数 | 数十人 |
| **第四境·破碎虚空/飞升** | 武道之极，一剑劈开天门，抗下天劫飞升而去 | 本地缓存溢出，系统打开数据分流通道 | 千年难见一位 |

### 各境界详述

#### 第一境：炼气 / 锻骨

- **入门条件**：需要有达到门槛的"根骨"（灵魂数据的基础兼容性），约十人中有一人可入武道门槛
- **修行过程**：通过特定吐纳功法打通窍穴，引天地灵气入体
- **能力范围**：力能扛鼎、刀枪难入、奔跑如风、五感强化
- **瓶颈**：大部分修行者终其一生停留在此境界。突破到宗师需要极高的悟性（灵魂数据密度）和机缘
- **底层**：完成基础硬件握手，获得比普通灵魂更大的本地缓存空间

#### 第二境：宗师 / 御物

- **标志**：真气外放——内力不再局限于体内
- **代表能力**：
  - 摘叶飞花：以真气附着外物，临时赋予其全新属性（落叶坚逾精钢）
  - 踏雪无痕：借用"凝冰之理"或"大地承载之意"，轻功绝世
  - 隔空打物：真气在数丈之外仍有杀伤力
- **社会地位**：宗师级高手已是江湖顶尖存在，足以开宗立派
- **底层**：获得对图层物理引擎局部接口的非法调用权限

#### 第三境：天象 / 领域

- **标志**：武道领域——在自身周围构建一个"自定义法则"的区域
- **代表能力**：
  - 领域压制：十丈之内万物遵从他的武道意志
  - 天象调动：可向系统提交伪造的气象日志，强行调动天雷地火
  - 属性剥夺：在领域内可剥夺敌人的"不坏金身"
- **存在意义**：天象境强者是足以影响一国存亡的战略级存在
- **底层**：获得图层级管理员的沙盒权限

#### 第四境：破碎虚空 / 飞升

- **实质**：武道修为超越了第一图层的算力承载极限
- **飞升过程**：丹田真元蕴含"天地震颤"的磅礴力量 → 斩向天幕裂痕 → 天道降下九重天劫（系统防御机制） → 硬抗雷罚 → 天光撕开 → 灵魂迁移至上层图层
- **飞升后果**：经过系统通道飞升的灵魂**会被记忆清洗**（区别于传送塔）
- **底层**：本地缓存溢出迫使系统打开数据分流通道向上层迁移

## 二、武学流派分类

### 按修行路径分类

| 类别 | 特征 | 代表 |
|------|------|------|
| **外家功夫** | 以锻体为主，注重筋骨皮肉 | 金刚门、铁布衫一脉 |
| **内家功法** | 以培元养气为主，注重经脉气海 | 太极、八卦、形意一系 |
| **剑道** | 人剑合一，以锋锐之意贯穿武道 | 诸大剑派 |
| **奇门杂术** | 机关暗器、毒功药典、幻术 | 各类偏门小派 |
| **禁忌功法** | 以燃烧生命力/他人灵魂为代价，短时间越境爆发 | 魔道功法（详见下文） |

### 禁忌功法（重要设定）

禁忌功法并非"邪恶"，而是**代价极高的系统后门调用**。

- **原理**：燃烧自身或他人的灵魂数据密度，换取短暂的越境算力
- **表象**：修炼者头发花白、容颜迅速衰老、精气神衰败（"走火入魔"的另一种形态）
- **底层**：非法提权——用"软件自毁"的方式获得瞬间的高权限访问
- **社会观念**：正道不齿，但在乱世中不乏为求生存而踏入此道者

> **走火入魔的真相**：超越自身承受极限的功法修行，导致气海崩裂——即本地带宽过载烧毁。

## 三、兵器体系

### 兵器品级

| 品级 | 特征 | 稀有度 |
|------|------|--------|
| 凡铁 | 普通铁器，凡人使用 | 极多 |
| 精钢 | 名匠锻造，削铁如泥 | 较多 |
| 灵器 | 蕴含微量灵气波动，可被真气催动增幅 | 稀有 |
| 灵宝 | 拥有自主灵性，可与持有者共鸣 | 极稀有 |
| 先天至宝 | 图层诞生之初即存在，蕴含底层代码碎片 | 传说级 |

> **先天至宝**：部分"先天至宝"实际上是初代人类遗留的硬件碎片（如秘钥碎片），在图层表象中被包装成了"天地孕育的至宝"。

## 四、天道与天劫

"天道"是第一图层众生对**系统规则**的笼统称谓。

| 现象 | 表象 | 底层真相 |
|------|------|---------|
| 天道感应 | 因果报应、天人合一的玄妙感悟 | 系统对灵魂数据波动的反馈循环 |
| 天劫（飞升） | 九霄雷罚，天道阻止凡人超越极限 | 系统防御机制，试图阻止缓存溢出 |
| 天谴（禁忌） | 对滥用禁忌功法者降下惩罚 | 非法操作触发的系统异常处理 |
| 天象异变 | 红月、地震、群星失序 | 底层参数波动的表象映射 |
