## 一、图层定位

第一图层是系统三大测试图层中**最贴近原始人性的沙盒**。它剥夺了一切高科技赋能，将人类灵魂置于古典农耕文明的框架之下——饥饿、寒冷、疾病、有限的寿命、宗族血脉的羁绊与古典道德的约束。

**系统测试目标**：在最原始的生存压力下，测试人类的爆发力、忠诚、背叛、牺牲与野心。

**表象**：这是一个王朝争霸、快意恩仇的古代冷兵器世界。江湖门派林立，庙堂波诡云谲，武道高手可以飞檐走壁、开碑裂石。没有人知道脚下的大地不过是一行行代码的投影。

## 二、物理引擎规则

### 基础参数

| 参数 | 设定 |
|------|------|
| 重力 | 标准地球重力（略微可被武学修改） |
| 物质构成 | 古典元素体系：金木水火土 |
| 能量形式 | **真气/内力**——第一图层独有的能量数据格式 |
| 人体结构 | 标准人体 + **经脉气海系统**（图层专属数据结构） |
| 科技上限 | 冷兵器时代上限，火药被参数锁定禁止发展 |
| 自然法则 | 大体遵循古典物理，但武学修为可局部调用底层接口 |

### 真气与经脉

- **经脉**是第一图层物理引擎中独有的数据传输通道，人人生来具备，但需通过修行"打通"
- **气海/丹田**是灵魂数据的本地缓存区，容量因人而异
- **真气**是第一图层的局域能量数据格式，修行者可以通过吐纳功法从"天地灵气"（环境能量池）中汲取

> **底层真相**：所谓"灵气浓郁"的洞天福地，不过是系统分配了更多本地算力的区域节点。

## 三、关键数值

- **传送塔残存数量**：2-3座（深度休眠，被自然掩埋）
- **三百年周期律**：系统每隔约300年自动下调局部降水概率/土壤肥力，触发王朝更迭
- **代理人数量**：1-2名（如隐世国师、武林超然存在）
- **清道夫出现频率**：极低，表现为"盲眼神僧""无常判官"等形态
- **飞升记录**：极其罕见，图层数千年历史中有确切记载者不超过个位数
